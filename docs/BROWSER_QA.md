## 프레임 간격 수정과 제한

기존 코드는 매번 마지막 그리기 시간을 현재 시각으로 바꾸면서 남은 시간을 버렸습니다. 60 Hz 입력을 2초간 모의 실행했을 때 42회만 그리는 문제를 재현했습니다. 남은 시간을 유지하도록 수정했고 `tests/app-media.test.mjs`에서 목표 60회(±1)를 확인합니다.

브라우저 MediaRecorder 출력은 여전히 기기·디코더·화면 부하의 영향을 받는 가변 프레임 레이트입니다. 최종 4초 테스트 MP4의 평균은 약 **21.7 fps**였습니다. 고정 30 fps 인코딩이나 실시간 성능을 보장하지 않으며, 이 결과를 숨기지 않습니다. 프레임 간격 수정이 하드웨어 코덱·시작 지연을 해결했다는 뜻도 아닙니다.

## 재현 방법

앱을 실행한 뒤 별도 터미널에서 테스트 원본을 만듭니다. FFmpeg는 이 수동 점검에만 필요하며 앱 실행·`npm test`의 의존성이 아닙니다.

```sh
ffmpeg -f lavfi -i testsrc2=size=640x360:rate=30 \
  -f lavfi -i sine=frequency=440:sample_rate=48000 \
  -t 4 -c:v libx264 -pix_fmt yuv420p -c:a aac moment-test.mp4
```

다음 내용을 UTF-8 `captions.srt`로 저장합니다.

```srt
1
00:00:00,000 --> 00:00:02,000
첫 번째 자막
두 번째 줄

2
00:00:02,000 --> 00:00:04,000
마지막 장면 🌊
```

1. 데스크톱 브라우저에서 영상을 업로드하고 자막 탭에서 SRT를 불러옵니다.
2. 저장하고 새로고침한 뒤 영상·자막을 확인합니다.
3. MP4/H.264·720p로 내보냅니다. 탭을 계속 활성 상태로 둡니다.
4. 원본과 다른 경로에 결과를 저장하고 별도 플레이어로 끝까지 재생합니다.
5. `ffprobe`와 디코더로 컨테이너·영상·오디오를 확인합니다. 가변 프레임 레이트를 그대로 검사하도록 time base를 유지합니다.

```sh
ffprobe -v error -show_entries format=duration,size:stream=codec_name,codec_type,width,height,avg_frame_rate -of json output.mp4
ffmpeg -v error -i output.mp4 -map 0:v:0 -c:v rawvideo -fps_mode passthrough -enc_time_base demux -f null -
ffmpeg -v error -i output.mp4 -map 0:a:0 -f null -
```

| 재생 중 삭제 확정 / 검색 초안 입력 후 취소 | 확정은 현재 위치 유지하며 정지; 취소는 추가 편집 없이 페이지·검색 초안 유지 |
| 행 문구 편집 후 범위 삭제 창 열기·취소 | 창을 열 때 기존 blur/change가 행 편집을 반영할 수 있음; 취소가 미적용 행 초안 보존을 보장하지 않음 |
| 프로젝트·패널·모달 변경 또는 IME 조합 중 확정 | 오래된 요청/조합 중 실행 차단 |
| 유효한 복구 실패 설정으로 편집 | 메모리 편집·실행 취소 허용, 자동 저장은 계속 차단; 설정 백업 필요 |
| 한·영·중·Tab·모바일 | 번역된 양끝 포함 입력 이름·오류 초점·빈 목록 초점 확인 |

UI 행 번호는 1부터, API `captions.remove`는 0부터 시작하는 `captionIndex`와 `count`를
사용합니다. 현재 배열 위치는 편집 뒤 바뀌므로 불확실한 삭제를 무조건 재시도하지 마세요.

## 문구 위치 백분율 입력 · 수동 확인 대기

**실제 브라우저의 픽셀·글자 기준점·드래그·안전 영역·모바일 배치는 아직 검증하지 않았습니다.**

| 수동 점검 | 기대 동작 |
|---|---|
| 제목·크레딧·공통 자막·선택 카드에서 위치 열기 | 각 레이어의 가로/세로 백분율 표시, 패널에서 모바일 접근 가능 |
| 제목 X 5–95 / Y 6–93, 나머지 0–100 | 변경 축에 실제 모델 한도 적용; 빈 값·비유한 값·범위 밖 변경은 반영 없이 수정 가능 |
| 한 축만 소수로 변경 | 다른 축의 원래 저장값 그대로, 두 축 함께 변경 시에도 한 번 실행 취소 |
| 가져온 제목 X 2% 유지하며 Y만 수정 | 손대지 않은 X를 새 편집 한도에 맞춰 자르지 않음 |
| 표시된 같은 값 재입력·취소 | 대화상자 자체는 추가 프로젝트 편집·정지·실행 취소 기록 없음; 여는 클릭의 기존 blur/change 반영과 구별 |
| 내용·시간·스타일 및 다른 레이어 비교 | 위치 외 값 불변, 공통 자막 위치는 개별 자막 위치가 아님 |
| 프로젝트·레이어·카드·미디어·패널 변경 / IME | 오래된 요청 또는 조합 중 확정 차단 |
| 유효한 복구 실패 설정 | 메모리 편집/실행 취소 가능, 저장소 쓰기 재개 없음; 별도 설정 백업 필요 |
| 한·영·중·Tab·모바일 | 백분율 입력 이름·오류 초점·명시적 적용·작은 화면 버튼 접근 확인 |

수치는 모델 좌표입니다. 실제 렌더러의 기준점·텍스트 맞춤·위치 제한이 달라 최종 글자
테두리나 중심점의 픽셀 정렬을 이 검사로 보장하지 않습니다.

## 자막 일치별 검색과 선택한 일치 바꾸기 · 수동 확인 대기

**실제 브라우저의 텍스트 선택·포커스·blur/change·IME·모바일 배치는 아직 검증하지 않았습니다.**

| 수동 점검 | 기대 동작 |
|---|---|
| 한 행에 같은 단어 2개·여러 페이지의 일치 | 이전/다음이 각 문자열을 따로 선택, 현재/전체는 행이 아닌 일치 횟수 |
| 끝/처음 일치에서 다음/이전 | 작성 배열 전체에서 순환, 해당 페이지/정확한 UTF-16 문자열 선택 |
| 대소문자·정규식 문자·이모지·겹치는 패턴 | 일반 대소문자 구분·비중첩 일치, 정규식/Unicode 정규화 없음 |
| 선택한 일치 바꾸기 후 다음 | 해당 문자열만 한 번에 실행 취소 가능, 대체 문구를 선택하고 다음은 삽입 구간 뒤부터 탐색 |
| 대체 문구 안에 검색어 포함 | 자동으로 다시 바꾸거나 즉시 다음으로 진행하지 않음; 이후 다음의 탐색/순환 확인 |
| 동일 대체·빈 결과·2,000 초과 결과 | 동일 대체는 무변경, 빈/초과 결과는 일부 수정 없이 거절 |
| 검색/대체 초안·미적용 행 편집·오래된 일치 | 초안 유지, 낡은 문구를 덮어쓰지 않고 편집 완료/다시 선택 안내 |
| 행 입력 후 검색 버튼을 실제 클릭 | 기존 blur/change 반영 여부 확인; 미적용 행 초안 보존을 가정하지 않음 |
| 타임라인 밖 자막·혼합 기준·메타데이터 | 검색 대상 포함, 교정으로 시간·화자·키워드·순서 변경 없음 |
| 한·영·중·Tab·모바일·실행 취소 | 접근성 이름·선택 범위·초점과 한 단계 되돌리기 확인 |

검색은 작성 문구의 일치이며 렌더링된 자막 발생 횟수와 다릅니다. 모두 바꾸기는 별도
동작으로 유지하며, 개별 선택 교정은 새 CLI/MCP 명령을 추가하지 않습니다.

## 원본 영상 구도 수치 입력 · 수동 확인 대기

**실제 브라우저 픽셀·영상 맞춤·드래그·모바일 배치는 아직 검증하지 않았습니다.**

| 수동 점검 | 기대 동작 |
|---|---|
| 데스크톱 화면 인스펙터·모바일 화면 패널 | 확대 옆 영상 구도 진입, 키보드만으로 이동/확대 입력·적용 가능 |
| 이동 −100..100%, 확대 100..300% 소수 입력 | 유한한 범위 내 값만 적용, 변경 필드만 한 번에 실행 취소 |
| 한 축만 변경·같은 값 표기 재입력 | 다른 축/확대 저장값 유지, 모두 같으면 명령·정지·기록 없음 |
| 0·양수·음수 이동, cover/contain 및 클립 줌 효과 | 영상 프레임 영역 기준 중앙/오른쪽·아래/반대 이동; 확대는 기존 맞춤·효과에 곱해짐 |
| 적용 전후 내용·시간·트림 대상·재생 위치 | 구도 필드 외 값과 현재 재생 위치 유지 |
| 취소·다른 입력에서 클릭해 열기 | 취소 자체는 변경 없음; 기존 입력 blur/change 반영과 구별 |
| 프로젝트·미디어·문맥·패널 교체·IME | 오래된 요청·조합 중 확정 차단, 유효한 현재 진입점으로 초점 복귀 확인 |
| 원본 미준비·유효한 복구 실패 설정 | 설정 편집 가능하나 즉시 영상 표시를 보장하지 않음; 저장 잠금 유지·설정 백업 필요 |
| 한·영·중·Tab·모바일 | 번역·입력 이름·오류 초점·작은 화면 접근 확인 |

원본 픽셀 정렬이나 전체 캔버스 기준 이동으로 해석하지 마세요. 실제 잘림·빈 영역·
레이어별 화면 구성은 별도 브라우저 확인이 필요합니다.

## 브라우저 자막 가져오기 시간 기준 · 수동 확인 대기

**실제 브라우저 파일 선택·대화상자 초점·IME·미디어 동기화는 아직 검증하지 않았습니다.**

| 수동 점검 | 기대 동작 |
|---|---|
| 자막 가져오기 열기 | 전용 파일 입력, 원본 미디어 기본값, 전체 교체 경고와 명시적 교체/취소 |
| 파일 선택만 하고 취소 | 기존 자막 교체 없음; 파일 선택 자체로 적용하지 않음 |
| 원본 시계 SRT/VTT | 원본 길이로 파싱, 기존 source 방식 유지 |
| 클립 [8..12,0..4], 원본 자막 0..2 내보내고 재가져오기 | 1배 출력 4..6 / 2배 출력 2..3을 편집된 출력으로 선택하면 저장 timeline 4..6 |
| 반복 클립 출력 자막 재가져오기 | 이미 펼쳐진 구간을 타임라인 자막으로 유지, 원본 자막 역복원 아님 |
| 잘못된 UTF-8·한도·유효 자막 없음 | 기존 자막 유지, 오류 수정/재시도 가능 |
| 읽기 중 파일/시계/프로젝트/미디어/선택/모달 변경 | 오래된 결과 반영 차단, 최신 파일과 기준으로 다시 확인 |
| 가져온 뒤 컷·배속 변경·실행 취소 | 기존 타임라인 기준 규칙과 전체 교체의 실행 취소 확인 |
| 한·영·중·Tab·Enter·IME·모바일 | 파일/기준/경고/확정 이름과 초점, 조합 중 확정 차단 확인 |

파일의 실제 시간 기준은 사용자가 확인해야 합니다. 밀리초 양자화·스타일·화자·키워드
손실을 프로젝트 복원으로 설명하지 말고, 전체 교체 전에 설정 JSON을 백업하세요.
