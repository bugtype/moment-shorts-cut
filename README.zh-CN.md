# Moment · 短视频工作室

**在浏览器中完成视频剪辑、字幕制作和导出，让素材成为短视频。**

[English](README.md) · [한국어](README.ko.md) · **简体中文**

[![CI](https://github.com/bugtype/moment-shorts-cut/actions/workflows/ci.yml/badge.svg)](https://github.com/bugtype/moment-shorts-cut/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Moment 是本地优先的视频编辑器，提供韩语、英语和简体中文界面。无需把媒体上传到应用服务器，即可剪辑片段、应用模板、添加字幕或旁白并导出短视频。无需账户或 API 密钥。

编辑器也提供共享编辑命令、可导出 SRT/VTT/TXT 的项目 JSON CLI，以及供 AI 客户端使用的本地 stdio MCP 服务器。项目仍处于早期阶段；依赖特定浏览器或编解码器前，请查看[已验证行为和剩余限制](docs/BROWSER_QA.md)。

## 快速开始

需要 **Git 和 Node.js 20 或更高版本**，包括 npm。没有需要安装的 npm 依赖，也没有构建步骤。

```sh
git clone https://github.com/bugtype/moment-shorts-cut.git
cd moment-shorts-cut
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。编辑器自带 **12 秒动态图形示例**，不导入素材也能体验模板和导出。示例字幕仅供编辑演示；示例没有可转写的语音。

编辑时保持服务器运行；按 `Ctrl+C` 停止。服务器绑定到 `127.0.0.1`，只提供 `dist/` 下的文件。应用使用 JavaScript 模块、Worker 和浏览器存储，因此应打开 HTTP 地址，不要直接双击 `dist/index.html`。

### 界面语言

在语言选择器中选择 **한국어**、**English** 或 **简体中文**。已保存的选择优先于受支持的浏览器语言；两者均不可用时使用韩语。若浏览器存储不可用，当前会话仍可切换语言，但刷新后可能无法保留选择。

切换界面语言**不会翻译**项目名称、字幕、标题、署名、说话人名称、导入文件或已保存的自定义模板内容。现有韩语演示和内置模板的示例文字仍保留韩语；应用示例内容仍需明确执行编辑操作。界面语言也不会改变语音识别语言，请根据原始音频另行选择。下方截图和成片保留原始韩语内容。

### 制作第一个短视频

1. **媒体：** 导入视频，或继续使用示例。在**画面**中选择 9:16、4:5、1:1 或 16:9 并调整构图；在时间线上裁剪、分割和排列片段。
2. **模板：** 选择构图。**仅应用样式**保留现有文字；**应用示例内容**会替换标题、署名和定时文字，但保留视频及对白字幕。
3. **字幕：** 导入 SRT/VTT、手动编写，或从语音在本地生成字幕。检查文字和时间。在**标题**和**效果**中设置大标题及定时文字。
4. **音频：** 添加音频文件，或授权麦克风后录制旁白。调整起始位置和音量，与原始音频配合。
5. **导出：** 选择可用的 MP4/WebM 格式以及 720p 或 1080p。**导出完成前保持标签页可见**，之后播放下载的文件检查结果。

顶部文件夹图标打开**项目文件**，窄屏也保留此入口。**使用指南**仍提供设置导入/保存。

**使用指南 → 查找工具**用韩语、英语或简体中文关键词搜索十个固定入口，不搜索编写内容。选择结果会显示并聚焦字幕检查、画面调整等现有控件；只有输出时间跳转和项目文件会打开原有对话框。不会替你执行编辑、下载、文件选择、识别、录音或导出。

用 Tab 移到结果按钮再激活；输入时按 Enter 不会自动选择结果。Escape 或取消会将焦点返回使用指南。项目、媒体或面板变化后，过期结果拒绝跳转，原有忙碌/恢复保护仍生效。不新增顶部按钮或快捷键，也不保存查询及搜索历史。目标工具行为不变；离开输入框打开使用指南时，原有草稿仍可能按正常失焦行为提交。

| 操作 | 保存位置或用途 |
|---|---|
| **保存** | 保存到浏览器存储 |
| **项目文件 → 保存编辑设置** | 下载 `.moment.json` 元数据备份 |
| **项目文件 → 导入编辑设置** | 恢复已保存的设置文档 |
| **项目文件 → 图形文字 (.txt)** | [审阅已存标题、署名和卡片](INTEGRATIONS.md#그래픽-문구-검토용-txt)；不是项目备份 |

设置保存和恢复文件均不得超过 **10 MiB（10,485,760 个 UTF-8 字节）**；超限会被拒绝，不会截断内容。另行保留原始视频和音频：**JSON 不包含媒体文件**。

**项目名称草稿：** 同一项目仅刷新状态时（如音频准备完成），顶部名称输入保持不变。离开输入框以结束编辑；允许提交的更改会去掉首尾空白，空名称使用**未命名短视频**。提交前的草稿不包含在项目设置、备份或浏览器自动保存中。项目名称值改变或项目被替换（包括导入、重置、撤销/重做）时，输入框仍会重新同步，即使替换项目的名称相同。

## 功能

| 工作内容 | 可用工具 | 重要边界 |
|---|---|---|
| 视频和时间 | 裁剪、分割、排序、删除、变速、平移/缩放、撤销/重做；亮度、对比度、饱和度、暗角、缓慢缩放及进度条 | 一个源视频、一条视频轨道；片段边界淡入淡出/闪光不重叠片段 |

**在自己的场景中比较模板：** 打开模板预览，选择**当前场景**，再切换**当前样式 / 所选样式**。两者使用同一冻结的原始画面和当前时间线时间；所选样式按现有“仅应用样式”规则作用于独立项目副本。保留已编写的标题、署名、卡片文字及字幕，但视觉设置和相关层的时间可能不同。比较本身不应用模板、编辑、保存、跳转或播放音频；打开模板预览仍按原有行为暂停播放。准备好后使用现有应用按钮。对话框默认使用**示例**，媒体未就绪时也仍可使用。项目、媒体、选择或播放头变化后请重新打开。这是视觉预览，不是原始分辨率或源视频逐帧精确导出。

**复用卡片样式：** 在选中的定时卡片上选择**复制样式**，选中另一张卡片，再选择**粘贴样式**。只复制颜色、字号/描边、背景样式、呈现方式和动画；文字、时间、位置/宽度、角色、类型和启用状态保持不变。副本只存在于编辑器内存中，不使用系统剪贴板或持久存储；之后修改或删除源卡片不会改变副本。实际粘贴更改可一次撤销；样式相同则不改变任何内容。

### 分享自定义模板

在模板库的单张自定义模板卡片中导出文件，再在另一浏览器通过模板库导入。导入会以新 ID 在**我的模板**下添加**新副本**，不会覆盖已有模板、更改收藏或自动应用到当前项目。预览后再选择仅应用样式或应用示例内容。

**一起迁移多个已保存模板：** 在模板库选择**导出我的模板集合**，再在另一浏览器使用现有导入操作。

- **追加副本：** 在**我的模板**下生成新 ID，不覆盖或自动应用；空集合不添加任何内容。
- **整体验证：** 集合最多 6 MiB，每个模板最多 256 KiB；合并后的模板库须通过验证且不超过 20 项。无效项或保存失败会拒绝整个追加操作。
- **不是完整恢复：** 不含收藏、项目或媒体。[集合契约](INTEGRATIONS.md#사용자-템플릿-컬렉션)

**模板文件加载期间：** 单个/集合导入成功时，仅在完成时仍打开**模板**面板才刷新模板库。若已切换到其他面板，完成处理不会重建该面板或清除未提交的输入。返回模板可查看更新后的库，原有搜索词仍生效。切换面板或项目本身不会取消此模板库导入，也不会将模板应用到项目。这不是草稿自动保存，也不改变项目/SRT/VTT 导入的冲突规则。

**复制已保存的自定义模板：** 在卡片上选择**创建副本…**，编辑建议的副本名称并确认。名称去掉首尾空白后须非空，最多 40 个 UTF-16 代码单元。新 ID 保存**已存**设置、卡片、时间和元数据的独立副本，不捕获当前项目构图。不会自动应用或修改项目、撤销记录、收藏；20 项模板库须有空位。源模板变化后请重新打开。取消或写入失败保留原模板库，失败后可重试；损坏而被阻止的模板库不能复制。

**重命名已有模板**无需再创建副本。名称会去掉首尾空白，不能为空，最多 40 个 UTF-16 代码单元。ID、收藏、已保存样式/内容及当前项目保持不变；即使 20 个位置都已占满也能重命名。名称不必唯一；搜索及导出文件名使用新名称。取消或保存失败会保留原项；保存失败后窗口保持打开，允许重试。

**用当前配置更新已有自定义模板：** 在模板卡片上选择**用当前配置更新**，再确认**更新**。系统在确认时读取当前构图，替换已保存的样式和内容，同时保留模板 ID、名称、类别和收藏。已有 20 个模板也可使用，因为它替换一项而非追加副本。不会修改当前项目、媒体或其他项目，也不会自动应用模板。如需保留旧版本，请先导出文件；此操作是覆盖，不提供版本历史。取消或保存失败会保留原项，并允许在保存失败后重试。

自定义模板保存、复制、重命名或更新成功后，若该模板库视图仍为当前视图，焦点移到现有/新模板的**名称按钮**。目标已删除或被筛选隐藏时，改为移到**模板搜索框**。存储失败会保留对话框供重试，不把焦点移到外部。此管理操作的焦点转移不适用于取消、名称未变的确认或文件导入。

| 文件 | 包含什么 | 不会做什么 |
|---|---|---|
| 项目 JSON | 编辑设置、时间线和字幕 | 嵌入源媒体 |
| 单个模板 JSON | 已保存的样式、标题/署名/卡片文字、关键词及说话人名称 | 备份整个模板库或当前项目 |
| 自定义模板集合 JSON | 按当前顺序保存的全部自定义模板 | 恢复收藏、内置模板、界面偏好或项目 |
| SRT/VTT | 编辑后的字幕文字及时间 | 保留视觉样式或媒体 |
| TXT | 按输出顺序排列的字幕文字 | 恢复时间或充当项目备份 |

**分享模板前请检查已保存文字。** 文件不包含视频/音频，但标题、署名、卡片、全局关键词和说话人名称可能包含私人信息。单个模板导入接受最多 256 KiB 的 UTF-8 JSON，包括可选的文件开头 BOM；最多 20 项的模板库必须有空位。无效文件或保存失败不改变模板库及当前项目。[文件契约和恢复](INTEGRATIONS.md#개별-사용자-템플릿-파일)说明格式/版本检查及连续选择文件的规则。浏览器模板库与 CLI/MCP 分离：后者可以[将导出的模板文档应用到当前项目](INTEGRATIONS.md#내보낸-템플릿을-climcp로-적용)，但不能列出或保存浏览器的自定义模板库。

CLI/MCP 也可通过 `template.export` [将当前构图导出为可移植模板](docs/MCP.md#export-the-current-composition-as-a-template)，不改变项目或浏览器模板库。保存样式及标题、署名、卡片内容，不包含对白字幕或媒体。

## 预览与时间调整参考

### 定位预览位置

**用键盘选择时间线片段：** 用 `Tab` 聚焦视频轨道的片段按钮，再按 `Enter` 或 `Space`，即可选择该片段、暂停并跳到该次出现的起点，不受水平滚动位置影响。仅选择变化时保留已聚焦的按钮；鼠标/触摸仍跳到片段内按下的位置。选择本身不编辑、保存或增加撤销记录。内容、时间或缩略图变化仍可能重建轨道，并不保证所有焦点或输入草稿都被保留。

**文字图层的时间线按钮：** 显示顺序和轨道结构不变时，普通标题/署名/卡片的文字与时间更新会保留现有按钮。文字、位置和宽度仍会更新；结构变化或需沿用原有渲染逻辑时仍可能重建轨道。修改时间可能让指针下的目标移动，因此不保证编辑后立即点击就能激活它。选择/跳转规则不变，也不会保存输入草稿。

**预览快捷键：** 不按修饰键时，`,` / `.` 按输出时间的 1/30 秒后退/前进，用于查看剪辑或字幕边界。方向键仍按变速前的时间线时间移动 1 秒。细步移动参考 30 fps 输出，不代表源视频逐帧精度，也不会吸附到帧网格；原有的帧间偏移会保留。在编辑输入框、输入法组字期间、使用修饰键或忙碌时会忽略这些快捷键。

**文字 / 效果选项卡：** `Tab` 进入当前选项卡；不按修饰键的 `←` / `→` 循环切换并立即激活，`Home` / `End` 选择首个/最后一个。面板重绘后焦点仍跟随所选选项卡。`Tab` 离开选项卡列表，`Enter` / `Space` 保留按钮原生激活，`↑` / `↓` 保留原生行为。切换选项卡本身不跳转、不改变播放状态，也不编辑或保存项目；选项卡外的预览方向键跳转保持不变。

**检查剪辑边界：** 使用播放滑杆旁的**上一个剪辑点 / 下一个剪辑点**，暂停并跳到当前位置之前/之后的编辑片段边界，包括起点和终点。位于边界时会移至相邻边界，而不是停在同一处。不按修饰键的 `[` / `]` 功能相同；编辑输入或表单控件、输入法组字、打开对话框、忙碌或尚未连接会话媒体的恢复状态下会忽略。到达端点且该方向无其他边界时，不改变播放状态。变速只改变输出时间显示，不改变所访问的剪辑点。导航不会改变片段选择、编辑、保存或撤销记录。这不保证源视频逐帧定位精度。

**跳转到输出时间：** 点击预览时间显示，输入 `2.5`、`01:02.5` 或 `00:01:02.5`，然后选择**跳转**。该值是**变速后的输出时间**，允许零到输出结束位置。确认后暂停并跳转；取消不改变播放状态。不会编辑、保存或添加撤销记录。项目或媒体源发生变化后请重新打开窗口；忙碌和恢复保护仍然有效。这是时间跳转，不保证帧或音频采样级精度。

### 选择画面比例

**画面**提供 **9:16、4:5、1:1、16:9** 数字预设。导出质量按短边计算，预览/预览 PNG 使用下列固定画布。

| 比例 | 预览 / 预览 PNG | 720 导出 | 1080 导出 |
|---|---|---|---|
| 9:16 | 540×960 | 720×1280 | 1080×1920 |
| 4:5 | 540×675 | 720×900 | 1080×1350 |
| 1:1 | 960×960 | 720×720 | 1080×1080 |
| 16:9 | 960×540 | 1280×720 | 1920×1080 |

改变比例不会自动重新设计现有文字/卡片，请检查构图和文字位置。现有项目文件仍可读取。新的 4:5 文件需要更新版 Moment；即使 Schema 版本不变，旧版也会拒绝该比例。可移植模板不包含或改变比例。尺寸不保证符合平台要求或原生编解码器支持。

### 调整源视频构图

在桌面画面检查器的缩放旁，或紧凑屏幕的**画面**面板中选择**视频构图…**，输入可含小数的百分比，再点击**应用**。

| 控件 | 含义 |
|---|---|
| 水平 / 垂直偏移 | −100–100%；0 表示适配视频居中，正值相对视频画框区域向右/向下移动 |
| 缩放 | 100–300%；乘以现有填充/适应比例及片段效果缩放 |

仅一起应用修改字段，可一次撤销；未改值保留原始存储精度。内容、时间和当前播放头位置不变。取消或相同值不新增命令或暂停；打开对话框仍可能触发其他输入框原有的失焦/更改处理。项目、媒体或上下文变化后请重新打开。恢复失败但设置有效时仅在内存中编辑，仍需备份设置。媒体未就绪时也可编辑元数据，因此缺少源文件时可能没有可见变化。偏移不是源像素坐标，也不一定相对整个画布；可能裁剪或露出空白，不保证安全区域。

**预览单轴拖动：** **开始拖动前仅按住 Shift**，即可沿一轴移动所选视频、标题、署名、全局字幕或定时卡片。首次非零屏幕位移较大的轴决定方向，相等时选水平；松开 Shift 后仍锁定到此次拖动结束。另一轴保留原始存储值，移动轴仍受原有拖动范围限制。开始后才按 Shift，或开始时同时按 Ctrl/Meta/Alt，仍为自由拖动；无修饰键的鼠标/触摸拖动不变。实际移动可一次撤销，无位移不增加历史。指针取消或失去捕获会保留并提交中途移动，而不是回滚。键盘/数值编辑可用**视频构图…**或**位置…**；此功能不吸附或自动居中。

**仅供查看的构图辅助：** 在桌面**画面**或紧凑屏幕对应面板中启用**三分法网格**，两处控件同步。它将整个构图三等分，不表示源视频裁剪区域或平台安全区。默认关闭；本次会话切换面板/项目仍保留选择，刷新后重置。不吸附对象，不改变播放、项目、撤销或存储，也不进入预览 PNG、输出分辨率 PNG 或视频导出。

### 从预览编辑时间

**用播放头填写裁剪值：** 选择片段，将播放位置移入所选片段，再按开始/结束旁的目标图标（**将播放头位置填入开始时间 / 将播放头位置填入结束时间**）。它会暂停并仅将精确源时间填入对应字段，保留另一端草稿；在明确点击**应用所选区间**（**画面**面板中的**应用范围**）前，不跳转、编辑、保存或创建撤销记录。重复源片段按所选的出现位置计算，变速不改变捕获的源时间。端点值可能形成无效范围，应用前需修正；最短 0.1 秒限制不变。位于所选片段外时只提示移入，不修改草稿。这不保证源视频逐帧精度。

**设置精确速度：** 可继续使用预览速度预设，或选择**自定义…**，输入 **0.25–4** 范围内的有限倍率并点击**应用**。当前值不经舍入预填，非预设倍率也保留在速度控件中。这改变整个项目的预览和输出速度，而非单个片段。标题、署名和定时卡片按现有速度编辑规则调整时间；已保存的片段、字幕时间及音频偏移数据保留原有时间基准。取消或应用相同值不会编辑、保存、暂停或增加撤销记录。项目或媒体改变后请重新打开对话框。不保证音高、编解码器行为或帧精度。

### 循环完整预览

在**画面**面板中开启**循环播放完整预览**后开始播放。此选项仅用于当前会话，默认关闭，刷新后也关闭；不改变项目 JSON、保存或撤销记录。

| 播放类型 | 循环行为 |
|---|---|
| 完整预览 | 结束后从头播放；暂停时仅开启选项不会自动播放 |
| 定时卡片预览 | 仍在该卡片结束处停止 |
| 导出 | 无论预览设置如何，始终只输出一遍 |

关闭后当前一遍继续到结束，但会取消等待中的重启。手动暂停/跳转、隐藏标签页或更换媒体优先；不保证无缝循环。

### 保存预览图像

| 画面操作 | 图像与播放行为 |
|---|---|
| **保存预览 PNG** | 不暂停，复制已显示的预览位图 |
| **输出分辨率 PNG… → 暂停并保存 PNG** | 选择短边 720/1080 输出尺寸（默认 1080），暂停并按该尺寸重新绘制当前已解码场景 |

**输出分辨率 PNG**在确认时取景，不是打开窗口时；打开或取消不会暂停播放。它使用已有合成渲染器重新绘制解码后的源媒体，不是放大预览位图。不会跳转、初始化音频/录制、编辑或保存项目，也不增加撤销记录。请等待字体加载、定位和媒体准备完成后重试；上下文变化或新请求会阻止过期下载。本地文件名为 `项目名.scene-宽x高.png`。更多像素不恢复源细节，也不保证精确选择帧。这仅用于浏览器，不是 CLI/MCP PNG 渲染器。

在**画面**中选择**保存预览 PNG**，下载**点击时显示的**已编辑画布：9:16 为 540×960、4:5 为 540×675、1:1 为 960×960、16:9 为 960×540。包含画布中的视频、文字和效果，不含 DOM 辅助线、选择手柄或音频；不会重新渲染为 1080p、跳转、暂停、修改项目/撤销记录或上传媒体。它独立于 MediaRecorder，不是源视频逐帧导出。忙碌或尚未连接会话媒体的恢复状态会阻止捕获；新请求或项目/媒体改变会取消过期下载。正常播放推进不会改变点击时的快照。

## CLI 与集成

CLI 编辑**项目设置和字幕**。在仓库根目录运行：

```sh
# Create a sample project.
node cli/moment.mjs init --out project.json

# Apply the included explainer composition.
node cli/moment.mjs exec template.apply --project project.json --args-file examples/explainer.json --out edited.json

# Export captions with edits and playback speed reflected in the timestamps.
node cli/moment.mjs exec captions.export --project edited.json --out captions.srt
node cli/moment.mjs exec captions.export --project edited.json --json '{"format":"vtt"}' --out captions.vtt
node cli/moment.mjs exec captions.export --project edited.json --json '{"format":"txt"}' --out captions.txt

# Replace matching caption text without changing timing or speaker metadata.
node cli/moment.mjs exec captions.text.replace --project edited.json --json '{"find":"하루","replacement":"하루의 기록"}' --out corrected.json

# Make all captions larger without replacing their text or timing.
node cli/moment.mjs exec captions.style.update --project corrected.json --json '{"patch":{"captionSize":48}}' --out styled.json

# List commands and their input schemas.
node cli/moment.mjs commands
```

现有输出文件默认受保护；仅在确定替换时使用 `--overwrite`。对 `exec` 添加 `--dry-run` 可预览结果而不写文件。JSON 输入不得超过 10 MiB（10,485,760 字节）。

生成的参数对象可通过 [`--args-file -`](INTEGRATIONS.md#표준-입력으로-json-인수-전달) 管道传入；读取到 EOF 为止，仍有 UTF-8 10 MiB 限制。不要与 `--json` 同用。

### 选择集成方式

| 需求 | 使用方式 | 入口 |
|---|---|---|
| 编辑项目 JSON 或导出字幕文件 | Node CLI，保护现有输出 | [命令契约和文件流程](INTEGRATIONS.md) |
| 为 AI 提供项目指引 | 仓库技能，无需全局安装 | [Moment 编辑器技能](.agents/skills/moment-editor/SKILL.md) |
| 连接 AI 客户端 | 本地 stdio MCP：`node cli/mcp.mjs` | [客户端设置、工具、错误和恢复](docs/MCP.md) |
| 接入自己的代码 | 同页面 `window.moment` 或可复用服务/适配器 | `node examples/use-editor-service.mjs` |

运行 `node examples/use-mcp-client.mjs` 可执行握手 → 导入 → 编辑 → SRT → 重启/重新导入示例。它启动本地 Node 进程，并把导出的文档保存在内存；不会写入用户文件或连接浏览器。

**可选精简 MCP 工具列表：** [`--tools`](docs/MCP.md#choose-a-smaller-tool-list-optional)选择单个进程的直接调用工具，默认仍为全部 41 个。文档交接建议包含 import/get；若省略 get，可保存已选 `render.plan` 的 `data.project` 文档，而非整个计划。这不是安全或只读边界；选中的 batch/preview 仍保留完整嵌套命令集。

**MCP 进程退出后，修改会丢失。** 调用 `moment_project_get`，通过客户端获准的文件流程保存 `structuredContent.data`。内置服务器只有一个临时 `session` 项目，不是当前浏览器项目。

**`render.plan` 不会生成 MP4。** CLI 和内置 MCP 都不上传媒体或编码视频。自定义远程主机需自行提供传输、身份验证和存储。外部 AI 客户端可能把项目文字发送到其提供商；分享私人字幕前请检查该客户端的隐私设置。

## 选择工作流程

### 字幕

| 任务 | 使用方式 | 注意事项 |
|---|---|---|
| 按页读取原始字幕 | [`captions.list`](INTEGRATIONS.md#저장된-자막을-나눠-조회) | 每页最多 50 条原始字幕，再用当前索引调用 `captions.update`。时间为变速前；实时页面不是快照或项目备份。 |
| 插入字幕或删除范围 | [`captions.insert` / `captions.remove`](INTEGRATIONS.md#자막-하나-추가연속-범위-삭제) | 使用当前原始数组索引，不排序或调整其他字幕时间。结果不确定时先重新读取；盲目重试可能影响错误的字幕。 |
| 编辑单条字幕 | [`captions.update`](INTEGRATIONS.md#자막-하나만-수정) | 不必重传所有字幕，即可修改文字、时间、说话人或关键词。先查询当前数组位置；时间基准和估计时间标记保留。 |
| 为多行应用不同的已审核修正文案 | [纯文字批处理示例](examples/correct-caption-text.mjs) | 查询当前索引，预检后批量应用最多 20 个 `captions.update` 文字补丁。不同于字幕替换导入，只修改文字并保留时间和元数据。原子性仅限单次批处理。 |
| 修正重复用语 | [`captions.text.replace`](INTEGRATIONS.md#자막-문구-일괄-교정) | 区分大小写、非重叠的字面匹配；无正则表达式或 Unicode 归一化。时间、说话人/关键词和顺序不变。空白或过长结果使整次编辑失败。浏览器预览出现次数，实际更改可一次撤销。 |
| 在剪辑中定位字幕 | 行操作**在视频中查看** | 单次出现直接跳转，重复出现可选择位置。仅时间导航，不修改项目。 |
| 逐个查看匹配项 | 浏览器上一项/下一项搜索控件 | 循环遍历每次字面匹配，包括同一行内多次匹配及裁剪外字幕；打开所在页并选中精确子串。当前/总数是匹配次数，不是行数；导航不跳转、编辑或保存。 |
| 只替换一个匹配 | 选择搜索结果后点击**替换当前匹配** | 只替换该子串，可一次撤销；保留时间和元数据。选中替换文本，下一项从其后继续。相同替换不编辑，空白或超长结果会拒绝。先完成待提交的行编辑并重新选择过期匹配，不覆盖旧内容。 |
| 替换编写行范围内的文字 | 输入查找/替换文字后选择**替换指定范围…** | 核对捕获的字面文字及包含首尾的**从 1 开始**行号（默认选中匹配所在行，否则为当前页第一行；均仅一行）。实时计数限于该范围，确认后可一次撤销；范围外、时间及元数据不变。不是持久选择，单项/全部替换与搜索导航保持独立。 |
| 查找/替换跨行文字 | 两行查找与替换输入框 | 输入或粘贴真实换行；`\n` 仍是字面的反斜杠和 n，不转换为换行。仍区分大小写、非重叠匹配、不使用正则；替换保留字幕时间和元数据。 |
| 修正固定字幕延迟 | [`captions.timing.shift`](INTEGRATIONS.md#자막-시간을-앞뒤로-이동) | 选择 source/timeline 及**变速前**有符号秒数。先选择可选编写行范围，再按基准过滤；省略范围则移动全部匹配字幕。任一结果越界即全部拒绝。浏览器实际更改可一次撤销。 |

| 批量或按范围分割长字幕 | [`captions.split.long`](INTEGRATIONS.md#긴-자막을-전체-또는-범위로-분할) | 12/18/24 字素目标、估计时间并去除分割边界空白。API 或浏览器**范围…**可指定编写行；原有分割按钮仍处理全部字幕。 |
| 在光标处分割一条字幕 | [`captions.split`](INTEGRATIONS.md#자막-하나를-커서-위치에서-분할) 或行内分割操作 | 保留原文和元数据；按字素数估算时间，不做语音对齐。不能在表情符号/组合字符内部切分。与批量分割长字幕不同。 |
| 合并相邻字幕 | [`captions.merge`](INTEGRATIONS.md#인접한-자막-합치기) 或**与下一条字幕合并** | 合并下一条已编写行，可跨页。时间基准、说话人、关键词必须相同，时间按顺序且不重叠；间隙也显示合并文字。浏览器可一次撤销。 |
| 改变外观 | [`captions.style.update`](INTEGRATIONS.md#자막-스타일-수정) | 只修改指定的字号、位置、颜色、动画及两位说话人的名称/颜色，无需重传项目。普通 SRT/VTT 不含视觉样式。 |
| 清除关键词强调 | **文字 → 对白 → 清除关键词强调…**，再确认 | 一次清除全局及所有字幕的关键词，可一次撤销；正文、时间、说话人及高亮框样式不变。取消或已为空不新增编辑；项目变化后重新打开确认。 |
| 保留现有字幕并追加多行 | [`captions.append`](INTEGRATIONS.md#기존-자막을-유지하며-여러-행-추가) | 追加非空字幕数组，保留输出范围外的现有行及元数据。合计最多 10,000 行；不排序、移时或去重。重复成功请求会添加重复字幕。 |
| 导入字幕文字 | [`captions.import`](INTEGRATIONS.md#srtvtt-본문을-명령으로-가져오기) | 默认 `replace` 替换全部字幕；`mode:"append"` 保留现有行并追加解析的字幕。传入内容而非路径，并明确 source/timeline 的**变速前**时间，而非输出时间。API：100,000 个 UTF-16 代码单元；浏览器文件：2 MiB。 |

<a id="duplicate-clip-range"></a>

**复制片段范围…**的首尾位置默认均为当前所选片段。按原顺序复制一次，紧接原区块插入，选中首个副本并跳至其起点，可一次撤销。范围必须完整存在，结果不得超过 1,000 个片段；范围/容量错误会整体拒绝，不留下部分副本。取消本身不增加编辑。源字幕随副本重复，时间线字幕和音频偏移保留数值；标题、署名、卡片不复制，其时间按新输出时长一次性缩放。这复制的是源区间，不是媒体文件，也不保存多片段选择状态。

**位置…**编辑图层的归一化锚点，而非渲染后文字的边框。修改标题坐标时，水平范围为 **5–95%**、垂直为 **6–93%**；署名、全局字幕和卡片的两个轴均为 **0–100%**，允许小数。修改的轴一起应用，可一次撤销，不改变内容、时间或样式。未改动轴保留原始存储值，即使导入的标题坐标超出当前编辑范围。取消或相同值不新增编辑；紧凑布局中也可从面板进入。项目、图层或媒体改变后请重新打开；恢复失败但设置有效时，内存编辑仍需备份设置。不同图层的锚点、文字适配及位置限制不同，不保证视觉居中、像素对齐或位于安全区域内。

在**移动显示时间…**对话框点击**将播放头位置填入开始时间**，仅将当前播放位置换算为变速后的输出秒，填入草稿并更新计算后的结束时间。检查后点击**移动**才应用；填入本身不会编辑、暂停、跳转、保存或增加记录，超出范围不会自动裁短。

例如将 0–3 秒卡片移到 7–10 秒：选择**移动显示时间…**，输入 `7`，检查计算后的结束时间，再点击**移动**。时长、ID、堆叠顺序、内容、样式及其他卡片保持不变。实际修改会暂停播放，但保留当前播放头位置，不跳到卡片处。整段必须位于输出范围内，超出范围或时长过长会拒绝，而不是裁短。取消或相同起点不会编辑、暂停、跳转、保存或增加记录。卡片、标题及署名的开始/结束输入显示已存小数，不舍入为两位，也不限制在 0.1 秒步长网格。未设置的标题/署名结束时间保持空值/null；只读摘要仍可能舍入。编辑提交时机和区间校验不变。小数时间使用普通浮点精度，不保证采样精度。项目、媒体或所选卡片变化后请重新打开。恢复失败但设置有效时仅允许内存编辑，浏览器保存仍被阻止，请单独备份设置。

字幕/卡片的开始和结束字段不能为空；请在有效区间内明确输入 `0` 或小数秒。字幕使用**变速前**的源/时间线秒，卡片使用**变速后**的输出秒；可选的标题/署名结束时间仍可留空/null，表示持续到输出结束。

选择**移动片段…**，输入 1 到片段总数之间的位置并点击**移动**。实际移动可一次撤销：选择跟随该片段，暂停并跳到其新起点。现有箭头使用相同操作。该片段的裁剪草稿保留，但不保证其他面板草稿在编辑后保留。项目、媒体或选择变化后请重新打开。源区间及已保存的字幕、标题和卡片时间不被改写；源时间字幕的派生位置遵循新顺序，时间线字幕保留绝对时间。若恢复失败但已读取有效设置，仍可在内存中移动片段；浏览器保存保持禁用，请在刷新前下载设置备份。


**删除片段范围…**删除一个连续范围，不保存多选组。确认后选择该范围后第一个保留片段；若没有后继，则选择最后一个保留片段，并跳到其起点。源字幕条目保留，时间线字幕时间和音频偏移保持绝对值；标题、署名和定时卡片的输出时间随缩短的时间线按比例调整。这种结构编辑会清除裁剪草稿，取消则保留。项目、媒体或选择变化后请重新打开。恢复失败但设置有效时仍仅在内存中编辑，请在刷新前备份设置文件，而不是依赖浏览器保存。

**仅保留间隙…**先合并全部当前片段的源区间，再保留完整源时长内的补集。例如 12 秒源媒体中保留了 2–4 和 6–8 秒，结果为 0–2、4–6、8–12 秒，不保留原有排序和重复。检查源区间（每页 20 个）、数量及变速后输出时长后确认；一次可撤销替换会选择第一个结果片段并跳到其起点。

没有剩余间隙、任一正长度结果间隙短于 **0.1 秒**或结果超过 **1,000 个片段**时会拒绝，不会静默丢弃小间隙。最短限制仅属于此 UI 操作，不是所有导入项目片段的通用要求。源字幕值保留，因此恢复的源区间可能重新出现对应字幕；时间线字幕和附加音频偏移保持绝对值，标题/署名/卡片输出时间按新时长比例调整。这不是无损渲染或可逆历史；使用撤销/设置备份，不要期待再次反转恢复顺序及重复。上下文变化后请重新打开；恢复失败但设置有效时，刷新前仍需备份设置。

## 隐私和限制

**媒体留在设备上，但应用并非完全离线。** 字体从 Google Fonts 加载；自动字幕从 jsDelivr 下载代码，并从 Hugging Face 及相关运行时来源下载模型/运行时资源。语音推理在浏览器 Worker 中进行。网络请求和信任边界见 [SECURITY.md](SECURITY.md)。

| 输入或项目限制 | 上限 |
|---|---|
| 视频 / 附加音频 | 500 MiB / 100 MiB |
| 项目设置 JSON 保存/恢复 / SRT 或 VTT 输入 | 10 MiB / 2 MiB，UTF-8 |
| 片段 / 源字幕条目 | 1,000 / 10,000；每条 2,000 个 UTF-16 代码单元 |
| 自定义模板 / 定时文字层 | 20 / 12 |

已有 1,000 个片段时，必须先删除片段才能继续分割。

**这些是验证上限，不保证内存或编解码器能力。** 浏览器存储不是备份：媒体和设置分别写入，保存失败后可能失去同步。请保留原始媒体并定期导出项目 JSON。

**自动字幕：** 原始视频必须为 **180 秒或更短**，即使裁剪后更短也不能绕过原始时长限制。所选音频最多处理 180 秒。识别、手动说话人标签及估计的分割时间需要检查。

## 音频与视频导出

<a id="audio-mix"></a>

**在音频中平衡混音：** 根据项目及文件连接状态，可在同处调整已有的两个项目音量。

| 音频控件 | 范围 |
|---|---|
| **原始视频音量** | 仅视频项目显示；与画面面板原有源音量为同一值 |
| **添加音频的音量** | 连接附加音频文件时显示 |

两者都是 0–100% 全局增益，不是逐片段混音或新增音频处理。视频项目不一定含音轨。这些值影响录制混音，与下述仅会话有效的监听静音分开。

**音频开始位置：** 输入输出视频秒数；若要从开头开始，请明确输入 `0`。空值或无效数字仅保留草稿并显示警告，不改变偏移、字幕或编辑记录。有效数字仍遵循原有范围限制和时间线字幕平移方式；不改变哪些字幕跟随附加音频。

**附加音频加载期间：** 成功完成时若当前打开的是**标题、效果、模板或画面**面板，完成处理不会重建该面板并清除未提交的输入。**音频、字幕和媒体**仍会按新源刷新。原有暂停、时间线/检查器更新及存储规则不变；不新增草稿自动保存，也不保证撤销或项目替换后仍保留草稿。

**预览静音不等于导出静音。** 扬声器按钮仅关闭您听到的声音，导出时也一样；录制混音仍遵循项目的原始音量和附加音频音量。需要无声混音时，将**两个音量都设为 0**。预览静音选择在导出、取消和重试期间保持，但仅属于当前会话，刷新后默认取消静音，不是保存到项目的字段。

### 录制选项

**视频导出：** 保持标签页可见；隐藏标签页会取消录制。MP4/WebM 支持取决于浏览器。录制实时进行，目标为 30 fps，不保证固定帧率。历史 4 秒 Chromium 测试平均约 21.7 fps；参见[实测报告](docs/BROWSER_QA.md)。

每次打开导出对话框时，两个选项均默认勾选。开始时固定本次请求的选择，不编辑/保存项目或增加撤销记录。

| 导出选项 | 取消勾选的影响 |
|---|---|
| **在视频中包含字幕** | 仅省略 Moment 的对白字幕层；勾选仍遵守项目的字幕可见性设置 |
| **包含音频** | 从录制流中省略音轨，而不是录制无声混音 |

包含音频的选择不改变项目音量或预览静音/监听。如需保留音轨但录制无声混音，请保持勾选并将两个项目音量设为 0。现有音频准备和浏览器编解码器检查仍然适用；取消勾选不能绕过音频准备错误。取消和重试不会混用旧请求的选项；重新打开对话框会再次默认勾选。

字幕选项对以下输出的影响：

| 输出 | 取消勾选的影响 |
|---|---|
| 录制视频 | 省略对白字幕；标题、署名、定时卡片及原始画面保留 |
| 导出前后的正常编辑预览、PNG 和模板预览 | 不变；录制中仍禁止保存 PNG |
| 录制中的预览 | 镜像所选录制结果，也反映省略字幕的选择 |
| SRT/VTT 外置字幕文件 | 不变；从字幕面板单独保存 |

这不会去除源像素中已有的文字，也不会在 MP4/WebM 中加入可开关的字幕轨道。CLI/MCP `render.plan` 没有新增开关，仍是计划而非视频编码。

## 存储与文件格式

<details>
<summary>存储、待处理导入和转写冲突</summary>

**存储：** 媒体保存在 IndexedDB，编辑状态保存在 localStorage。二者分别写入，保存失败可能不一致。存储属于当前浏览器和源；更改主机名或端口会打开不同存储区。清除浏览器数据、隐私模式或空间不足可能导致丢失工作。没有云同步或远程备份。

**待处理导入：** 读取文本文件或等待应用期间，如果项目发生变化，会拒绝导入；请重新选择文件以应用到当前项目。选择另一个 JSON/SRT/VTT 会使之前的待处理导入失效，即使新文件随后失败。这些检查保护已应用状态，不涵盖尚未提交的输入框草稿。

**待处理转写：** 如果源媒体或现有字幕发生变化，或项目已被替换，结果不会应用；附加音频结果还要求音频偏移和编辑时长不变。请针对新输入重新生成。外观更改仍可使用。保护对象是已应用编辑，不是未提交的输入草稿；检测到冲突不保证停止模型计算。

</details>

<details>
<summary>UTF-8、字幕格式和时间规则</summary>

**文本导入：** 项目 JSON 和 SRT/VTT 应保存为 UTF-8，支持开头的 UTF-8 BOM。字幕的 LF、CRLF、CR 换行会归一为 LF，同时保留正文中的换行。无效 UTF-8 被拒绝，不替换当前项目或字幕。不会自动检测或转换其他编码。

**字幕文件：** 选择 **SRT**、**VTT**、**TXT** 或 **审阅 TXT**，使用字幕面板唯一的保存按钮。默认 SRT；翻页后保留格式选择。

**普通 WebVTT：** 选择 **VTT**，或给 CLI/MCP 导出命令传入 `format: "vtt"`。不传 `format` 仍导出 SRT；仅把文件名改成 `.vtt` 不会选择 VTT。VTT 使用 `WEBVTT` 文件头和点分隔的毫秒，编辑后时间与文字转义规则相同。不导出丰富样式、区域或说话人元数据。VTT 拒绝 NUL 字符。无字幕时 CLI/MCP 返回 `WEBVTT\n\n`；浏览器不下载空字幕文件。

**选择文本导出：**

| 选项 | 内容 |
|---|---|
| **TXT** | 原有字幕段落，不含时间或说话人名称 |
| **审阅 TXT** | `.review.txt` 含变速后输出秒数、明确分配的非空说话人名称及正文；重复/重叠区间分别列出 |

审阅标题使用界面语言，编写的名称/正文不翻译。这是人工审阅列表，不是导入格式、实际显示保证、经音频核实的逐字稿或项目备份。两种模式均用 LF、无 BOM 的 UTF-8；空结果不下载文件。使用的名称也计入最终 2 MiB 限制，含 NUL 时拒绝。[CLI/MCP 选项与限制](INTEGRATIONS.md#자막-검토용-txt)

**普通 TXT：** 每个派生字幕区间一个段落，按片段、重复及 source/timeline 字幕在变速后的输出顺序排列。重复或分割片段可能重复词句；不是去重或逐词准确的转录。不含时间戳、ID、说话人、标题、卡片或样式。原样保留 `<>&`、空白和多行文字，使用 LF 换行，区间间一个空行，末尾一个换行。允许空行和小于毫秒的字幕，拒绝 NUL。空结果返回 `""`。SRT/VTT 导入不能导入这种 TXT，也无法恢复其时间。

**UTF-8 导出边界：** 拒绝输出孤立的 UTF-16 代理项，不会静默替换成 `U+FFFD`。检查范围包括 SRT/VTT/TXT 和审阅 TXT 的字幕文字、审阅中使用的说话人名称，以及图形清单输出的编写字段。

被剪掉或排除的字幕、未使用的名称和无关图形不会阻止指定范围的字幕导出。不做 Unicode 归一化或自动修复；有效配对的表情、组合字符和主动编写的 `U+FFFD` 不因本检查而改变。

模型及导入验证不变；项目 JSON 保留转义的代码单元以便恢复。按原意修正文字后再试。

**SRT/VTT 文字：** SRT/VTT/TXT 均拒绝 NUL（`U+0000`），不会自动删除。请修正/移除该字符后重试；项目 JSON 保留原始文字，导出失败不会覆盖已有输出文件。空行用于分隔字幕。导出拒绝空字幕或字幕内部空行，不会丢弃段落或重新分配时间。若要导出 SRT/VTT，请移除空行；项目 JSON 保留原始文字。支持普通多行字幕，输出中 CRLF/CR 归一为 LF。播放器对标记的支持各异，不保证通用兼容性。

**SRT/VTT 时间：** 裁剪和变速后，时间戳舍入到毫秒。若一条字幕舍入后的起止相同，则拒绝导出；请调整区间或播放速度。不会自动延长、删除或移动字幕，项目仍保留精确时间。

</details>

<details>
<summary>派生字幕预算和长字幕分割</summary>

**派生字幕限制：** 时间线字幕轨道和 SRT/VTT/TXT 导出最多支持 10,000 个编辑后出现区间及 2 MiB UTF-8 字幕文字；每次片段重复都计入。每个完整字幕文件另有 2 MiB 上限，包括转义、时间、分隔符、VTT 文件头和实际写入的 BOM（浏览器 SRT 含 BOM；浏览器 VTT/TXT 和 CLI/服务输出不含）。超限时拒绝整个派生输出，旧项目也同样适用；减少重复片段或字幕后可恢复。原始字幕编辑、项目 JSON、撤销和保存仍可使用。这些预算不保证界面响应速度或可用内存。

**长字幕分割：** 12/18/24 字目标及估计时间权重按字素簇计算，组合附加符号和连接表情保持完整，不做 Unicode 归一化。分割边界的空白按完整字素簇移除。此操作需要原生 `Intl.Segmenter`；不支持的运行时会报错并保持字幕不变。独立的 2,000 UTF-16 代码单元输入限制和 UTF-8 字节预算仍适用。分词取决于运行时的 Unicode 数据；估计时间仍需对照音频检查。

</details>

## 故障排查

- **页面无法加载：** 确认 `npm start` 仍在运行。4173 端口被占用时，停止另一服务器或把 `PORT` 环境变量设置为可用端口；使用服务器输出的地址。
- **视频无法打开或不能导出：** 尝试 H.264 MP4 或 WebM 输入，以及支持所需媒体 API 的其他浏览器。MOV 支持取决于内部编解码器。导出失败时也可尝试 720p。
- **自动字幕失败：** 使用有清晰语音的短原始素材，检查识别语言和网络，或导入 SRT/VTT 后手动编辑。内置示例不能转写。
- **项目似乎为空：** 回到相同浏览器、主机和端口。跨浏览器恢复 JSON 时，先重新连接原始视频和附加音频，再通过**项目文件 → 导入编辑设置**恢复。
- **已保存模板无法读取：** 格式错误的自定义模板或收藏会在当前会话中隔离；为保留原存储值，会阻止模板库保存、删除和收藏更改。项目本身能加载时，仍可使用内置模板及项目编辑。刷新只重试读取，不会修复模板库；不会自动删除或抢救条目。
- **恢复失败：** 编辑器暂停项目保存、媒体替换、录音和重置，以保留已存数据。如果设置可读，可在内存中编辑并在刷新前通过**项目文件 → 保存编辑设置**；这些编辑不会保存在浏览器中。刷新只重试加载，不能恢复缺失媒体或保证编解码器支持。未保存更改可能触发离开警告，但浏览器可能省略警告。[仅在当前标签页链接原始文件](#仅在当前标签页重新链接原始文件)可启用预览/导出，而不修复存储。

### 仅在当前标签页重新链接原始文件

若恢复失败但**已读取有效项目设置**，打开**项目文件 → 重新链接原始文件**。选择全部必需的原始视频/附加音频，明确确认它们是本项目的原始文件，再选择**连接到此标签页**。临时检测和编辑器实际媒体元素均完成加载后，才允许使用播放功能。

| 连接成功后 | 限制 |
|---|---|
| 预览、跳转、视频导出和预览 PNG | 仅当前标签页可用；不会自动播放 |
| 内存编辑、撤销及设置备份 | 仍可使用；刷新前下载设置文件 |
| 浏览器保存/自动保存、普通导入、重置、录音及语音识别 | 仍被阻止；存储错误和状态不会清除 |
| 刷新 | 必须重新提供原始文件；不是存储修复 |

文件名必须匹配，但**名称和时长相同并不能证明文件相同**。视频须覆盖已存时长和所有片段，不得更短，最多可多出 0.05 秒。附加音频须有有限正时长，但没有已存音频时长可供比较。原有视频 500 MiB、音频 100 MiB 限制仍适用。请保留真正的原始文件。链接本身不改变项目 JSON、撤销记录、IndexedDB 或 localStorage；项目/媒体条件变化、失败或取消不能授予过期的播放权限。

## 开发

```sh
npm test
node examples/use-editor-service.mjs
node examples/use-mcp-client.mjs
```

`npm test` 执行语法检查、编辑器回归检查，以及 CLI 文件 I/O、项目验证、MCP 生命周期/Schema/请求隔离、交互式 MCP 示例、字幕解析及本地 HTTP 服务器的 Node 测试。每个 `tests/app-*.test.mjs` 使用独立的模拟应用 VM 和 DOM；`verify.mjs` 保留合成与手势检查。完整回归集请运行 `npm test`。CI 配置包括 Linux 的 Node 20/22/24 和 Windows 的 Node 24；徽章链接到实际结果。

存储测试通过注入模拟事务失败检查取消、排队重试和保存状态，不验证真实浏览器配额不足、存储驱逐或崩溃恢复。

`dist/` 包含**维护中的应用源代码**，不是生成的构建输出：

```text
dist/               Browser UI, rendering, captions, and local persistence
  core/             DOM-free project model, validation, and editing commands
  integration/      Editor service and MCP adapter
cli/                Node.js project/caption CLI, stdio MCP session and transport
scripts/            Local preview server
examples/           Command arguments and runnable service/MCP examples
tests/              Node test suites
verify.mjs          Composition and preview-gesture regression checks
```

修改和问题报告参见 [CONTRIBUTING.md](CONTRIBUTING.md)，计划见 [ROADMAP.md](ROADMAP.md)，私密安全问题报告见 [SECURITY.md](SECURITY.md)。部分配套文档为韩语，MCP 设置和技能参考也提供英语内容。

[浏览器验证报告](docs/BROWSER_QA.md)记录 Chromium/macOS 对上传、字幕、持久存储和 MP4 导出的测试及性能边界。[QA.md](QA.md)说明回归覆盖。自动测试在必要时模拟浏览器 API，不证明麦克风、语音识别或跨浏览器兼容性。
