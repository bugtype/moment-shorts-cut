# Moment · 모먼트 쇼츠 스튜디오

**영상 편집부터 자막, 내보내기까지. 내 브라우저에서 만드는 쇼츠.**

[English](README.md) · **한국어** · [简体中文](README.zh-CN.md)

[![CI](https://github.com/bugtype/moment-shorts-cut/actions/workflows/ci.yml/badge.svg)](https://github.com/bugtype/moment-shorts-cut/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Moment는 한국어·영어·중국어 간체 UI를 제공하는 로컬 중심 영상 편집기입니다. 원본을 앱 서버에 업로드하지 않고, 필요한 장면을 자르고 템플릿·자막·내레이션을 더해 쇼츠로 내보낼 수 있습니다. 계정이나 API 키는 필요하지 않습니다.

자동화를 위한 공통 편집 명령, 프로젝트 JSON 편집·SRT/VTT/TXT 출력 CLI, AI 클라이언트용 로컬 stdio MCP 서버도 제공합니다. 아직 초기 단계의 프로젝트이므로 사용하려는 브라우저와 코덱에 대한 [검증 결과와 남은 범위](docs/BROWSER_QA.md)를 확인해 주세요.

## 빠른 시작

**Git과 Node.js 20 이상(npm 포함)**이 필요합니다. npm 의존성 설치나 별도 빌드 과정은 없습니다.

```sh
git clone https://github.com/bugtype/moment-shorts-cut.git
cd moment-shorts-cut
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)을 여세요. 첫 화면에는 **12초 모션 그래픽 샘플**이 있어 원본 영상 없이도 템플릿과 내보내기를 체험할 수 있습니다. 샘플 자막은 편집용 예시이며, 샘플에는 자동 인식할 음성이 없습니다.

편집하는 동안 서버를 켜두고, 종료할 때는 `Ctrl+C`를 누르세요. 서버는 `127.0.0.1`에서 `dist/`만 제공합니다. JavaScript 모듈·워커·브라우저 저장소를 사용하므로 `dist/index.html`을 더블클릭하지 말고 위 HTTP 주소로 접속하세요.

### 인터페이스 언어

언어 선택에서 **한국어**, **English**, **简体中文**을 고르세요. 저장한 선택이
지원되는 브라우저 언어보다 우선하며, 둘 다 없으면 한국어를 사용합니다. 브라우저
저장소에 기록할 수 없어도 현재 세션에서는 전환되지만 새로 고친 뒤 유지되지
않을 수 있습니다.

언어를 바꿔도 프로젝트 이름·자막·제목·크레딧·화자 이름·가져온 파일·저장된
사용자 템플릿 내용은 번역하지 않습니다. 기존 한국어 샘플과 기본 템플릿의 예시
문구도 유지하며 예시 내용 적용은 명시적인 편집입니다. 자동 자막의 인식 언어는
UI 언어와 별도로 원본 음성에 맞춰 선택하세요. 아래 화면과 출력 예시는 원래
한국어 내용을 보여 줍니다.

### 첫 쇼츠 만들기

1. **미디어:** 영상을 업로드하거나 샘플로 시작합니다. **화면**에서 9:16·4:5·1:1·16:9 비율과 구도를 맞추고, 타임라인에서 필요한 구간을 자르거나 나누고 순서를 바꿉니다.
2. **템플릿:** 원하는 구성을 고릅니다. **스타일만 적용**은 작성한 문구를 유지합니다. 예시 구성까지 적용하면 제목·크레딧·시간별 문구가 교체되며, 영상과 대사 자막은 유지됩니다.
3. **자막:** SRT/VTT를 불러오거나 직접 작성하고, 음성이 있는 원본은 로컬 자동 자막을 생성합니다. 문구와 타이밍을 확인하고 **타이틀·연출**에서 제목과 시간별 문구를 꾸밉니다.
4. **오디오:** 음성 파일을 추가하거나 마이크 권한을 허용해 내레이션을 녹음합니다. 시작 위치와 볼륨을 원본 음성에 맞춰 조절합니다.
5. **내보내기:** 지원되는 MP4/WebM 형식과 720p·1080p를 선택합니다. **완료될 때까지 탭을 화면에 표시한 상태로 유지**하고, 다운로드한 영상을 재생해 결과를 확인합니다.

상단 폴더 아이콘으로 **프로젝트 파일**을 엽니다. 좁은 화면에서도 사용할 수 있으며 **사용 가이드**에서도 설정 불러오기·저장을 할 수 있습니다.

**사용 가이드 → 도구 찾기**는 한국어·영어·중국어 간체 키워드로 정해진 도구 위치 10곳을
검색하며 작성한 내용은 검색하지 않습니다. 결과를 선택하면 자막 검토·화면 조절 같은
기존 컨트롤을 표시하고 초점을 옮깁니다. 출력 시간 이동과 프로젝트 파일만 기존 창을
엽니다. 편집·다운로드·파일 선택·음성 인식·녹음·내보내기를 대신 실행하지 않습니다.

Tab으로 결과 버튼에 이동해 실행하세요. 검색 입력 중 Enter는 결과를 자동 선택하지
않으며 Escape나 취소는 사용 가이드로 초점을 돌립니다. 프로젝트·미디어·패널이 바뀐
오래된 결과는 이동하지 않고 기존 작업 중·복구 보호를 유지합니다. 새 상단 버튼·단축키가
없고 검색어·검색 기록도 저장하지 않습니다. 이동한 도구의 동작은 그대로이며 사용 가이드를
열기 위해 입력란을 벗어나면 기존 초안 반영 동작이 일어날 수 있습니다.

| 작업 | 저장 위치·동작 |
|---|---|
| **저장** | 브라우저 저장소에 보관 |
| **프로젝트 파일 → 편집 설정 저장** | `.moment.json` 메타데이터 백업 다운로드 |
| **프로젝트 파일 → 편집 설정 불러오기** | 저장한 설정 문서 복원 |
| **프로젝트 파일 → 그래픽 문구 (.txt)** | [저장된 제목·크레딧·카드 검토](INTEGRATIONS.md#그래픽-문구-검토용-txt); 설정 백업 아님 |

설정 저장·복원 파일 모두 **UTF-8 10 MiB(10,485,760바이트)** 이하여야 하며 초과 출력은 자르지 않고 거절합니다. **JSON에는 미디어 파일이 포함되지 않으므로** 원본 영상과 오디오도 별도로 보관해야 합니다.

**프로젝트 이름 초안:** 같은 프로젝트에서 오디오 준비 완료처럼 상태만 갱신되어도
상단 이름 입력은 유지합니다. 입력란을 벗어나 편집을 마치면 허용된 변경을 반영하며,
앞뒤 공백은 제거하고 빈 이름은 **제목 없는 쇼츠**로 바꿉니다. 반영 전 초안은 프로젝트
설정·백업·브라우저 자동 저장에 포함되지 않습니다. 프로젝트 이름 값 변경이나 프로젝트
교체(불러오기·초기화·실행 취소/다시 실행 포함)는 이름이 같은 교체여도 입력을 다시 맞춥니다.

|---|---|

## 주요 기능

| 작업 | 지원 도구 | 알아둘 범위 |
| --- | --- | --- |
| 영상과 타이밍 | 자르기·분할·순서 변경·삭제·배속·위치/확대·실행 취소·다시 실행; 밝기·대비·채도·비네트·느린 줌·진행 막대 | 원본 영상 1개와 영상 트랙 1개. 경계 페이드·플래시는 클립을 겹치는 전환이 아닙니다 |
| 구성과 문구 | 기본 템플릿 16개, 검색·즐겨찾기, 개별 JSON 가져오기·내보내기를 지원하는 로컬 사용자 템플릿 최대 20개, 제목·크레딧 스타일, 시간별 문구 12개 | 스타일만 적용하면 문구 유지. 예시 구성은 제목·크레딧·시간별 문구를 교체합니다 |
| 자막과 오디오 | SRT/VTT 가져오기, 편집 후 SRT/VTT/TXT 저장, 문구 찾기·모두 바꾸기, 강조·등장 효과·수동 화자 2명; 추가 오디오 파일 또는 마이크 녹음 1개 | 기기 내 ASR은 Transformers.js 3.8.1 + `Xenova/whisper-tiny` 사용. 인식 결과와 분할 추정 시간은 검토가 필요합니다 |
| 저장과 자동화 | 브라우저 저장, 프로젝트 JSON, CLI, 저장소 스킬, stdio MCP; Canvas/Web Audio → MediaRecorder 출력 | JSON에는 미디어가 없습니다. CLI/MCP는 영상을 인코딩하지 않습니다 |

기본 템플릿은 리뷰 스토리, 강한 첫 문장, 브이로그, 설명, 인터뷰, 레시피, 랭킹, 제품 리뷰, 퀴즈, 시네마틱 구성을 제공합니다. 각 템플릿은 움직이는 샘플로 미리 볼 수 있습니다. 퀴즈 선택지와 카운트다운은 영상에 포함되는 그래픽이며 클릭형 투표가 아닙니다.

**초반 훅 6종:** 결과 먼저 보여주기, 실수 진단과 해결, A/B 빠른 비교,
10초 미니 실험, 3초 관찰 퀴즈, 통념 검증을 추가했습니다.
**템플릿 → 초반 훅**에서 고르고 **예시 구성까지 적용**하면 시간별 이야기 구성을,
**스타일만 적용**하면 작성한 문구를 유지한 모양을 사용합니다. 예시 적용은 제목·크레딧·카드를
교체하며 영상과 대사 자막은 유지합니다. 기본 12초 구성은 0~2 / 2~5 / 5~8 / 8초~끝,
퀴즈는 0~3 / 3~5 / 5~8 / 8초~끝입니다. **예시 적용 시 출력 길이가 12초 이상이면
초반 경계를 유지하고 12초 미만일 때만 비례 압축**합니다. **나중에 클립 길이·배속을
바꾸면 카드 시간도 비례 변경**되므로 초반 구간을 다시 확인하고 필요하면 시간을 조정하세요.
영상 재배열·분할화면·사실검증은 자동으로 하지 않으므로
영상과 예시 문구를 직접 맞추세요. [리서치·6개 적용 사례·작업 계획·검증 기준](docs/SHORTS_HOOK_TEMPLATES.md)을
확인하고, 커버 후보는 원하는 시점에서 [미리보기 PNG 저장](#미리보기-이미지-저장)으로 만드세요.
PNG는 현재 캔버스 크기 그대로 저장하며 YouTube 썸네일을 자동 등록하지 않습니다.
템플릿이 조회수나 완주율 상승을 보장하지는 않습니다.

**내 장면에서 템플릿 비교:** 템플릿 미리보기에서 **현재 장면**을 고른 뒤 **현재 스타일 /
선택한 스타일**을 전환하세요. 같은 정지 원본 프레임과 현재 타임라인 시간을 사용하며,
선택한 스타일은 별도 프로젝트 사본에 기존 스타일만 적용 규칙을 적용합니다. 작성한
제목·크레딧·카드 문구와 자막은 유지하지만 시각 설정·해당 레이어 시간은 달라질 수 있습니다.
비교만으로 템플릿 적용·편집·저장·탐색·오디오 재생은 하지 않습니다. 템플릿 미리보기를 열 때에는
기존처럼 일시 정지합니다. 실제 반영은 기존 적용 버튼을 사용하세요. 미디어가 준비되지
않으면 기본 모드인 **샘플**을 이용할 수 있습니다. 프로젝트·미디어·선택·재생 위치가 바뀌면 다시
여세요. 원본 해상도나 프레임 단위 정확도를 보장하는 출력 기능은 아닙니다.

**카드 모양 재사용:** 시간별 카드에서 **스타일 복사**를 누르고 다른 카드를 선택해
**스타일 붙여넣기**를 누르세요. 색상·글자 크기/테두리·배경 모양·표시 방식·등장 효과만 옮기며
문구·시간·위치/폭·역할·종류·표시 여부는 유지합니다. 복사본은 편집기 메모리에만 있고
운영체제 클립보드나 저장소에는 남기지 않습니다. 원본 카드를 나중에 수정하거나
삭제해도 복사본은 그대로입니다. 실제 변경은 한 번에 실행 취소하며 이미 같은
스타일이면 아무것도 바꾸지 않습니다.

### 사용자 템플릿 공유

갤러리의 사용자 템플릿 카드에서 개별 파일로 내보내고 다른 브라우저의
갤러리 가져오기를 사용하세요. 가져오면 새 ID의 **복사본**을 **내 템플릿**에
추가합니다. 기존 템플릿·즐겨찾기·현재 프로젝트를 바꾸거나 자동 적용하지
않습니다. 미리 본 뒤 기존처럼 스타일만 적용하거나 예시 내용까지 적용하세요.

새 저장·현재 구성으로 갱신·`template.export`는 시작 시간순 정렬 대신 캡처한
카드의 쌓임 순서를 유지합니다. 겹친 카드의 순서와 마지막 활성 헤드라인의
우선순위가 보존됩니다. 출력 범위 자르기와 상대 시간 규칙은 그대로이며,
기존 저장·내보내기 템플릿의 순서는 자동 복구하거나 다시 쓰지 않습니다.

**저장한 여러 템플릿을 함께 옮기려면:** 갤러리의 **내 템플릿 모음 내보내기**를 선택하고 다른 브라우저의 기존 가져오기로 여세요.

- **사본 추가:** **내 템플릿**에 새 ID로 추가하며 덮어쓰기·자동 적용은 없습니다. 빈 컬렉션은 아무것도 추가하지 않습니다.
- **전체 검증:** 컬렉션 최대 6 MiB, 각 템플릿 256 KiB. 합친 라이브러리의 검증과 20개 한도를 통과해야 하며, 잘못된 항목·저장 실패는 전체 추가를 거절합니다.
- **전체 복원 아님:** 즐겨찾기·프로젝트·미디어는 제외합니다. [컬렉션 계약](INTEGRATIONS.md#사용자-템플릿-컬렉션)

**템플릿 파일을 불러오는 동안:** 개별/모음 가져오기가 성공하면 완료 시점에
**템플릿**이 열려 있을 때만 갤러리를 갱신합니다. 다른 패널에 있다면 완료 처리만으로
그 패널을 다시 만들거나 미반영 입력을 지우지 않습니다. 갱신된 라이브러리는
템플릿으로 돌아가 확인하세요. 기존 검색어는 그대로 적용됩니다. 패널·프로젝트
변경 자체는 이 라이브러리 가져오기를 취소하지 않으며 프로젝트에 자동 적용하지
않습니다. 초안 자동 저장이나 프로젝트/SRT/VTT 가져오기의 충돌 규칙 변경은 아닙니다.

**저장한 사용자 템플릿 복제:** 카드의 **복제…**에서 제안된 사본 이름을 수정하고
확인하세요. 이름은 양 끝 공백 제거 후 비어 있지 않아야 하며 최대 40 UTF-16 코드
단위입니다. 새 ID에 **저장된** 설정·카드·시간·메타데이터를 독립 복사하며 현재
프로젝트의 구성을 캡처하는 기능이 아닙니다. 자동 적용·프로젝트/기록·즐겨찾기 변경은
없고 20개 라이브러리에 빈자리가 필요합니다. 원본이 바뀌면 창을 다시 열고, 취소·저장
실패 시 라이브러리는 유지되며 실패 후 재시도할 수 있습니다. 손상되어 차단된
라이브러리는 복제할 수 없습니다.

**사용자 템플릿 카드에서 이름만 변경**할 수 있습니다. 앞뒤 공백을 제거한
빈 문구가 아닌 이름을 최대 40 UTF-16 코드 단위로 입력하세요. 20개가 모두
차 있어도 가능하며 ID·즐겨찾기·저장된 스타일/내용·현재 프로젝트는 유지합니다.
같은 이름도 허용하고 검색·내보내기 파일명에는 새 이름을 사용합니다. 취소나
저장 실패 시 원래 이름을 유지합니다. 저장에 실패하면 창을 닫지 않아 다시
시도할 수 있습니다.

**현재 구성으로 기존 사용자 템플릿을 갱신**하려면 해당 카드의
**현재 구성으로 업데이트**를 누르고 **업데이트**로 덮어쓰기를 확인하세요. 확인 시점의 구성으로 저장된 스타일·내용을 교체하되
ID·이름·카테고리·즐겨찾기는 유지합니다. 새 항목 추가가 아니므로 20개가 차 있어도
가능합니다. 현재 프로젝트·미디어·다른 프로젝트는 바꾸거나 자동 적용하지 않습니다.
이전 구성이 필요하면 먼저 파일로 내보내세요. 버전 기록이 아닌 덮어쓰기입니다.
취소·저장 실패 시 원본을 유지하며 저장 실패 후 다시 시도할 수 있습니다.

사용자 템플릿 저장·복제·이름 변경·업데이트가 성공하면 해당 갤러리 화면이 여전히
현재 화면일 때 기존/새 템플릿의 **이름 버튼**으로 초점을 옮깁니다. 삭제되었거나 필터에
가려진 대상은 **템플릿 검색**으로 옮깁니다. 저장 실패 시에는 창을 유지하여 다시
시도할 수 있고 바깥으로 초점을 옮기지 않습니다. 이 관리 작업의 초점 이동은
취소·이름 변경 없는 확인·파일 가져오기에는 적용되지 않습니다.

| 파일 | 담는 내용 | 하지 않는 일 |
|---|---|---|
| 프로젝트 JSON | 편집 설정·타임라인·자막 | 원본 미디어 포함 |
| 개별 템플릿 JSON | 저장된 스타일·제목·크레딧·시간별 문구·키워드·화자 이름 | 전체 라이브러리나 현재 프로젝트 백업 |
| 사용자 템플릿 컬렉션 JSON | 저장된 모든 사용자 템플릿과 현재 순서 | 즐겨찾기·기본 템플릿·UI 환경설정·프로젝트 복원 |
| SRT/VTT | 편집 후 자막 문구·시간 | 화면 스타일·미디어 보존 |
| TXT | 출력 순서의 편집 후 자막 본문 | 시간 복원·프로젝트 백업 |

**공유 전에 저장된 문구를 확인하세요.** 영상·오디오는 없지만 제목·크레딧·
시간별 문구·공통 키워드·화자 이름에 개인정보가 있을 수 있습니다. 개별 템플릿 가져오기는
선택적인 파일 시작 BOM을 포함해 256 KiB 이하 UTF-8 JSON을 받으며, 최대
20개 라이브러리에 빈자리가 필요합니다. 잘못된 파일이나 저장 실패는 기존
라이브러리·현재 프로젝트를 바꾸지 않습니다. 형식·버전 검사와 연속 파일 선택
규칙은 [파일 계약과 복구](INTEGRATIONS.md#개별-사용자-템플릿-파일)를 참고하세요.
브라우저 라이브러리와 CLI/MCP는 별도입니다. CLI/MCP는 [내보낸 템플릿 문서를 현재 프로젝트에 적용](INTEGRATIONS.md#내보낸-템플릿을-climcp로-적용)할 수 있지만 브라우저 사용자 템플릿 목록을 읽거나 저장하지는 않습니다.

CLI/MCP의 `template.export`로 [현재 구성을 개별 템플릿 파일로 내보내기](docs/MCP.md#export-the-current-composition-as-a-template)도 가능합니다. 프로젝트·브라우저 라이브러리를 바꾸지 않고 스타일과 제목·크레딧·카드 내용을 담으며, 대사 자막·미디어는 포함하지 않습니다.

## 미리보기와 시간 조절

### 미리보기 위치 이동

**키보드로 타임라인 클립 선택:** `Tab`으로 영상 트랙의 클립 버튼에 초점을 두고
`Enter` 또는 `Space`를 누르면 해당 클립을 선택하고 일시 정지한 뒤 그 등장 구간의
시작으로 이동합니다. 가로 스크롤 위치와 무관하며 선택만 바뀔 때는 초점이 있는
버튼을 유지합니다. 마우스/터치는 기존처럼 클립 안에서 누른 위치로 이동합니다.
선택 자체는 편집·저장·실행 취소 기록을 만들지 않습니다. 내용·시간·썸네일이 바뀌면
트랙을 다시 만들 수 있으므로 모든 초점이나 입력 초안의 보존을 보장하지 않습니다.

**글자 레이어의 타임라인 버튼:** 표시 항목 순서와 트랙 구조가 같으면 일반적인
제목·크레딧·카드의 문구/시간 갱신에서 기존 버튼을 유지합니다. 문구·위치·폭은 계속
갱신하며 구조 변경이나 기존 렌더링 경로가 필요한 경우 트랙을 다시 만들 수
있습니다. 시간 수정으로 포인터 아래 대상이 움직일 수 있으므로 편집 직후 클릭이
항상 대상을 활성화한다고 보장하지 않습니다. 선택/탐색 규칙은 그대로이고 입력
초안을 저장하는 기능도 아닙니다.

**미리보기 단축키:** 보조 키 없이 `,` / `.`를 누르면 출력 시간 1/30초씩
뒤로/앞으로 이동해 자르기·자막 경계를 살펴볼 수 있습니다. 방향키는 기존처럼
배속 전 타임라인 1초씩 이동합니다. 세밀 이동은 30fps 출력 기준이며 원본 영상의
정확한 프레임 이동이나 프레임 격자 맞춤이 아니므로 시작 위치의 프레임 사이
오프셋을 유지합니다. 편집 입력란·IME 조합 중·보조 키 사용·작업 중에는 무시합니다.

**글자 / 연출 탭:** `Tab`으로 현재 탭에 진입하고, 보조 키 없는 `←` / `→`로
탭을 순환하며 바로 활성화합니다. `Home` / `End`는 처음/마지막 탭을 선택하고,
패널이 다시 그려져도 선택한 탭으로 초점이 이어집니다. `Tab`은 탭 목록을 벗어나며
`Enter` / `Space`는 버튼 기본 활성화, `↑` / `↓`는 기본 동작을 유지합니다.
탭 이동 자체는 재생 위치·재생 상태·편집·저장을 바꾸지 않으며, 탭 밖의 미리보기
방향키 탐색은 기존과 같습니다.

**컷 경계 확인:** 재생 막대 옆 **이전 컷으로 이동 / 다음 컷으로 이동**으로 일시 정지하고 현재 위치보다
앞·뒤의 편집 구간 경계로 이동하세요. 처음과 끝도 포함하며, 경계 위에서는 같은 위치가
아닌 인접 경계로 이동합니다. 보조 키 없는 `[` / `]`도 같은 기능이며 입력·폼 조작,
IME 조합, 열린 대화상자 또는 작업 중·세션 미디어가 연결되지 않은 복구 상태에서는 무시합니다. 해당 방향의 경계가
더 없는 끝점에서는 재생 상태도 바뀌지 않습니다. 배속은 출력 시간 표시만 바꾸며 방문할 컷은 바꾸지
않습니다. 클립 선택·편집·저장·실행 취소 기록은 변하지 않습니다.
원본 프레임 단위 탐색 정확도를 보장하는 기능은 아닙니다.

**출력 시간으로 이동:** 미리보기의 시간 표시를 누르고 `2.5`, `01:02.5` 또는
`00:01:02.5`처럼 입력한 뒤 **이동**을 누르세요. 배속 적용 후 출력 시간을
사용하며 0부터 출력 끝까지 이동할 수 있습니다. 확인하면 일시 정지하고,
취소하면 재생 상태를 바꾸지 않습니다. 편집·저장·실행 취소 기록은 만들지 않습니다.
프로젝트나 미디어 원본이 바뀌면 창을 다시 여세요. 작업 중·세션 미디어가 연결되지 않은 복구 상태에서는
이동이 차단됩니다. 정확한 프레임·오디오 샘플 탐색을 보장하는 기능은 아닙니다.

### 화면 비율 선택

**화면**에서 숫자 프리셋 **9:16·4:5·1:1·16:9**를 선택합니다. 출력 품질은 짧은 변 기준이며 미리보기/미리보기 PNG는 아래의 고정 비트맵을 사용합니다.

| 비율 | 미리보기 / 미리보기 PNG | 720 출력 | 1080 출력 |
|---|---|---|---|
| 9:16 | 540×960 | 720×1280 | 1080×1920 |
| 4:5 | 540×675 | 720×900 | 1080×1350 |
| 1:1 | 960×960 | 720×720 | 1080×1080 |
| 16:9 | 960×540 | 1280×720 | 1920×1080 |

비율 변경은 기존 문구·카드를 자동 재설계하지 않으므로 구도와 문구 배치를 다시 확인하세요. 기존 프로젝트 파일은 계속 읽을 수 있습니다. 새 4:5 파일은 업데이트된 Moment가 필요하며, 스키마 버전이 같아도 이전 빌드는 해당 비율을 거절합니다. 개별/모음 템플릿은 비율을 담거나 바꾸지 않습니다. 표의 크기는 플랫폼 규격 준수나 네이티브 코덱 지원 보장이 아닙니다.

### 원본 영상 구도 조절

데스크톱 화면 인스펙터의 확대 옆 또는 좁은 화면의 **화면** 패널에서 **영상 구도…**를
열고 소수 백분율을 입력한 뒤 **적용**하세요.

| 입력 | 의미 |
|---|---|
| 가로 / 세로 이동 | −100–100%; 0은 맞춤 영상의 중앙, 양수는 영상 프레임 영역 기준 오른쪽/아래 이동 |
| 확대 | 100–300%; 기존 채우기/맞춤 배율과 클립 효과 확대에 곱해짐 |

변경 필드만 한 번에 반영·실행 취소하며 손대지 않은 저장값의 정밀도는 유지합니다.
내용·시간·현재 재생 위치는 바꾸지 않습니다. 취소·같은 값은 명령이나 정지를 추가하지
않지만 창을 여는 클릭으로 다른 입력란의 기존 포커스 해제/변경 처리가 일어날 수 있습니다.
프로젝트·미디어·문맥이 바뀌면 다시 여세요. 유효한 복구 실패 상태의 메모리 편집은 설정
백업이 필요합니다. 미디어가 준비되지 않아도 설정은 편집하므로 원본이 없으면 화면 변화가
없을 수 있습니다. 원본 픽셀 좌표나 항상 전체 캔버스 기준인 비율이 아니며 잘림·빈 영역이
생길 수 있고 안전 영역 포함을 보장하지 않습니다.

**미리보기 한 축 드래그:** **드래그 시작 전에 Shift만** 누르면 선택한 영상·제목·크레딧·
공통 자막·시간 지정 카드를 한 축으로 옮깁니다. 처음 움직인 화면 거리에서 더 큰 축을
고르며 같으면 가로입니다. Shift를 놓아도 그 동작이 끝날 때까지 축을 유지합니다.
반대 축은 원래 저장값 그대로이며 이동 축에는 기존 드래그 한도를 적용합니다.
시작 후 Shift를 누르거나 시작할 때 Ctrl/Meta/Alt를 함께 누르면 자유롭게 이동하며,
수정 키 없는 마우스·터치 드래그는 그대로입니다. 실제 이동은 한 번 실행 취소하고
움직이지 않으면 기록을 만들지 않습니다. 포인터 취소·캡처 해제는 중간 이동을 되돌리지
않고 확정합니다. 키보드·수치 편집에는 **영상 구도…** 또는 **위치…**를 쓰세요.
자동 맞춤이나 중앙 정렬 기능은 아닙니다.

**보기 전용 구도 보조:** 데스크톱 **화면** 또는 좁은 화면의 같은 패널에서 **삼분할 격자**를 켜면 두 조작부가 동기화됩니다. 원본 영상의 잘림 영역이나 플랫폼 안전 영역이 아니라 전체 구성을 삼등분합니다. 기본은 꺼짐이며 이번 세션의 패널/프로젝트 변경에도 선택을 유지하고 새로고침하면 초기화합니다. 자동 맞춤·재생·프로젝트·실행 취소·저장을 바꾸지 않으며 미리보기 PNG·출력 해상도 PNG·영상 출력에는 포함하지 않습니다.

### 미리보기에서 시간 편집

**현재 위치로 트림 값 입력:** 클립을 선택하고 그 편집 구간 안으로 재생 위치를
옮긴 뒤 시작·끝 옆 표적 아이콘(**현재 위치를 시작값으로 입력 / 현재 위치를 끝값으로 입력**)을
누르세요. 일시 정지하고 선택한 필드에 정밀한 원본 시간을 채우며 반대쪽 초안은 유지합니다.
**선택 구간 적용**(**화면** 패널에서는 **구간 적용**) 전에는 탐색·편집·저장·실행 취소 기록이
생기지 않습니다. 반복된 원본도 선택한 편집 구간을 기준으로 하며 배속은 원본 값에 영향을
주지 않습니다. 끝점 입력으로 잘못된 범위가 되면 적용 전에 수정하세요. 최소 0.1초 조건은
유지됩니다. 선택 구간 밖에서는 안내만 표시하고 초안을 바꾸지 않습니다. 원본 프레임
단위 정확도를 보장하지 않습니다.

**정확한 배속 지정:** 미리보기의 기존 배속 목록을 쓰거나 **사용자 지정…**에서
**0.25–4** 범위의 유한한 배수를 입력하고 **적용**하세요. 현재 값을 반올림 없이
채우며 목록에 없던 값도 배속 표시로 유지합니다. 클립 하나가 아닌 전체 프로젝트의
미리보기·출력 속도를 바꿉니다. 기존 배속 편집 규칙에 따라 제목·크레딧·시간별 카드의
시간은 조정하고, 저장된 클립·자막 시간과 오디오 오프셋은 기존 기준을 유지합니다.
취소하거나 같은 값을 적용하면 편집·저장·일시 정지·기록이 생기지 않습니다. 프로젝트나
미디어가 바뀌면 창을 다시 여세요. 음높이·코덱 동작·프레임 정확도를 보장하지 않습니다.

### 전체 미리보기 반복

**화면** 패널에서 **전체 미리보기 반복**을 켠 뒤 재생하세요. 현재 세션에만 적용되며
기본값·새로고침 후에는 꺼집니다. 프로젝트 JSON·저장·실행 취소 기록은 바꾸지 않습니다.

| 재생 종류 | 반복 동작 |
|---|---|
| 전체 미리보기 | 끝나면 처음부터 재생; 정지 중 켜기만 해서는 재생하지 않음 |
| 시간별 카드 미리보기 | 기존처럼 해당 카드 끝에서 정지 |
| 내보내기 | 미리보기 설정과 무관하게 항상 한 번 출력 |

끄면 현재 회차는 끝까지 재생하지만 대기 중인 재시작은 취소합니다. 직접 정지·탐색,
탭 숨김·미디어 변경이 우선하며 끊김 없는 반복을 보장하지 않습니다.

### 미리보기 이미지 저장

| 화면 패널 동작 | 이미지·재생 동작 |
|---|---|
| **미리보기 PNG 저장** | 일시 정지 없이 표시된 미리보기 비트맵 복사 |
| **출력 해상도 PNG… → 일시 정지하고 PNG 저장** | 짧은 변 720/1080 출력 크기 선택(기본 1080); 일시 정지하고 현재 디코딩된 장면을 해당 크기로 다시 그림 |

**출력 해상도 PNG**는 창을 연 순간이 아닌 확인 시점의 장면을 사용하며, 열기·취소는
재생을 멈추지 않습니다. 미리보기 확대가 아니라 디코딩된 원본을 기존 합성 렌더러로
다시 그립니다. 탐색·오디오/녹화 초기화·프로젝트 편집/저장·실행 취소 기록은 없습니다.
글꼴 로딩·탐색·미디어 준비가 끝난 뒤 재시도하세요. 문맥 변경이나 새 요청은 오래된
다운로드를 차단합니다. 로컬 파일명은 `프로젝트이름.scene-너비x높이.png`입니다.
픽셀 수가 늘어도 원본 디테일 복원이나 정확한 프레임 선택을 보장하지 않습니다.
브라우저 전용이며 CLI/MCP PNG 렌더러가 아닙니다.

**화면**에서 **미리보기 PNG 저장**을 누르면 **누른 순간 표시된** 편집 캔버스를
내려받습니다. 9:16은 540×960, 4:5는 540×675, 1:1은 960×960, 16:9는 960×540이며 영상·문구·연출은
담지만 DOM 가이드·선택 핸들·오디오는 포함하지 않습니다. 1080p 재렌더링·탐색·일시
정지·프로젝트/기록 변경·미디어 업로드 없이 MediaRecorder와 별도로 동작합니다.
원본 프레임 단위 출력은 아닙니다. 작업 중·세션 미디어가 연결되지 않은 복구 상태에서는 차단되며 새 요청이나
프로젝트·미디어 변경은 오래된 다운로드를 취소합니다. 정상 재생 진행만으로는
클릭 시점의 복사본이 바뀌지 않습니다.

### 연결된 미디어 백업

설정 백업과 별도로 연결된 파일을 내려받으세요.

| 위치 | 동작과 파일 |
|---|---|
| **미디어**의 현재 영상 자산 아래 | **원본 영상 다운로드**: 연결된 영상의 바이트·이름·미디어 형식 그대로 저장하며, 영상 프로젝트에 파일이 연결되어 있을 때만 제공 |

두 동작 모두 컷·오프셋·볼륨·배속·문구·효과를 적용하지 않으며 변환·업로드·정지·탐색·
프로젝트/기록/저장소 변경이 없습니다. 프로젝트 JSON에는 여전히 미디어가 포함되지
않습니다. 없어진 원본을 복구하는 기능은 아니며, 재연결한 파일은 사용자가 제공한
파일이지 원본과의 동일성을 암호학적으로 검증한 파일은 아닙니다.

정상 준비 상태 또는 확인한 세션 전용 미디어 연결이 필요합니다. 작업 중·미디어를
사용할 수 없는 복구 상태·오래된 요청은 차단하며, 저장소 복구나 브라우저 저장 재개를
의미하지 않습니다.

## CLI와 외부 연동

CLI는 **프로젝트 편집 설정과 자막**을 다룹니다. 저장소 루트에서 실행하세요.

```sh
# 샘플 프로젝트 생성
node cli/moment.mjs init --out project.json

# 저장소에 포함된 설명형 템플릿 적용
node cli/moment.mjs exec template.apply --project project.json --args-file examples/explainer.json --out edited.json

# 편집 구간과 배속을 반영한 자막 출력
node cli/moment.mjs exec captions.export --project edited.json --out captions.srt
node cli/moment.mjs exec captions.export --project edited.json --json '{"format":"vtt"}' --out captions.vtt
node cli/moment.mjs exec captions.export --project edited.json --json '{"format":"txt"}' --out captions.txt

# 시간과 화자 정보를 유지하며 자막 문구 교정
node cli/moment.mjs exec captions.text.replace --project edited.json --json '{"find":"하루","replacement":"하루의 기록"}' --out corrected.json

# 문구와 시간을 유지하며 전체 자막 크기 조절
node cli/moment.mjs exec captions.style.update --project corrected.json --json '{"patch":{"captionSize":48}}' --out styled.json

# 명령 목록과 입력 스키마 확인
node cli/moment.mjs commands
```

기존 출력 파일은 기본적으로 보호합니다. 교체할 때만 `--overwrite`를 지정하세요. `exec`에 `--dry-run`을 붙이면 파일을 쓰지 않고 결과를 확인합니다. JSON 입력은 10 MiB(10,485,760바이트) 이하입니다.

생성한 인수 객체는 [`--args-file -`](INTEGRATIONS.md#표준-입력으로-json-인수-전달)로 파이프 전달할 수 있습니다. EOF까지 기다리며 UTF-8 10 MiB 한도는 유지됩니다. `--json`과 함께 쓰지 마세요.

### 연동 방식 선택

| 하고 싶은 일 | 사용할 기능 | 시작 위치 |
| --- | --- | --- |
| 프로젝트 JSON 편집·자막 파일 출력 | 기존 출력 파일을 보호하는 Node CLI | [명령 계약과 파일 작업](INTEGRATIONS.md) |
| AI에게 프로젝트 작업 지침 제공 | 전역 설치가 필요 없는 저장소 스킬 | [Moment editor 스킬](.agents/skills/moment-editor/SKILL.md) |
| AI 클라이언트 연결 | 로컬 stdio MCP 서버: `node cli/mcp.mjs` | [연결·도구·오류·복구 안내](docs/MCP.md) |
| 자체 코드에 연결 | 같은 페이지의 `window.moment` 또는 서비스/어댑터 | `node examples/use-editor-service.mjs` |

**디자인·카드 초안 보호:** 같은 페이지 보호는 **타이틀 → 타이틀 / 대사 / 크레딧**의 문구, 타이틀·크레딧 시간, **연출 → 구간별 문구**의 문구·시간에도 적용됩니다. 필드 입력을 확정하거나 원래 값으로 되돌리고 조합을 마친 뒤 상태를 다시 읽고 재시도하세요. 일반 타이핑으로 이미 반영한 값은 허용됩니다. 시간은 배속 후 출력 초이며 타이틀·크레딧의 빈 끝값은 끝까지 표시한다는 뜻을 유지합니다. 슬라이더·색상·움직임·색감은 포함하지 않습니다.

**미적용 자르기 구간 보호:** **화면** 패널의 시작·끝 초안과 조합 중인 입력에도 같은 보호가 적용됩니다. **구간 적용**을 누르거나 양쪽 원래 값으로 되돌리고 조합을 마친 뒤 상태를 다시 읽고 재시도하세요. 원본 초의 정밀도는 유지하며 손대지 않았거나 수치가 같은 입력은 초안으로 보지 않습니다. 모든 숫자 입력을 보호하는 기능은 아닙니다.

**프로젝트 이름 입력 보호:** `window.moment.execute`는 상단 이름에 아직 반영하지 않은 값이나 조합 중인 입력이 있어도 `CONFLICT`를 반환합니다. 이름 입력을 확정하거나 원래 값으로 되돌리고 조합을 마친 뒤 현재 상태를 다시 읽고 재시도하세요. 이름을 자동 확정·폐기하지 않으며 명시적 로컬 교체의 기존 동작은 유지합니다.

**입력 중인 자막 보호:** 같은 페이지의 `window.moment.execute`는 열린 자막 패널에 아직 반영하지 않은 행 입력이나 조합 중인 입력이 있으면 프로젝트 커밋 전에 `CONFLICT`를 반환합니다. 입력을 확정하거나 원래 값으로 되돌린 뒤 현재 상태를 다시 읽고 재시도하세요. API가 초점을 옮기거나 입력을 자동 저장·폐기하지 않습니다. 읽기·미리보기·실제로 커밋하지 않는 결과는 계속 허용됩니다. CLI/MCP, 명시적인 파일 가져오기, 직접 UI 편집·실행 취소는 바뀌지 않으며 모든 편집기 입력을 보호하는 기능은 아닙니다. [정확한 범위](INTEGRATIONS.md#브라우저와-파일-왕복)

`node examples/use-mcp-client.mjs`는 연결 → 가져오기 → 편집 → SRT → 재시작/재가져오기를 실행합니다. 로컬 Node 프로세스만 사용하고 결과 문서는 메모리에 보관합니다. 사용자 파일을 쓰거나 브라우저에 연결하지 않습니다.

**선택적 MCP 도구 목록:** [`--tools`](docs/MCP.md#choose-a-smaller-tool-list-optional)로 프로세스의 직접 호출 목록을 고를 수 있으며 기본은 전체 41개입니다. 문서 왕복에는 import/get을 권장합니다. get 대신 선택한 `render.plan`의 `data.project`도 전체 문서이며, 계획 전체를 저장하는 것은 아닙니다. 보안·읽기 전용 경계가 아니며 선택한 batch/preview의 전체 중첩 명령은 유지됩니다.

**MCP 프로세스가 종료되면 편집 내용이 사라집니다.** `moment_project_get`의 `structuredContent.data`를 클라이언트의 허용된 파일 저장 기능으로 보관하세요. 기본 서버의 임시 `session` 프로젝트는 열려 있는 브라우저 프로젝트와 별개입니다.

**`render.plan`은 MP4를 만들지 않습니다.** CLI와 기본 MCP 서버는 미디어 업로드·영상 인코딩을 제공하지 않습니다. 별도 원격 호스트에는 전송·인증·저장소 구현이 필요합니다. 외부 AI 클라이언트는 프로젝트 문구를 제공자에게 보낼 수 있으므로 비공개 자막을 전달하기 전에 해당 클라이언트의 개인정보 설정을 확인하세요.

| 클립 하나 분할 | [`timeline.split`](INTEGRATIONS.md#클립-구간-분할) | 출력 시간이 아닌 원본 시간 사용. 반복 구간의 위치·경계 확인. 전체 타임라인을 교체하지 않음. |
| 영상 효과 조절 | [`effects.update`](INTEGRATIONS.md#영상-효과-수정) | 내용·시간을 유지하며 밝기·대비·움직임·경계 효과·진행 표시 조절. 경계 효과는 교차 전환이 아님. |
| 출처 크레딧 지정 | [`credit.update`](INTEGRATIONS.md#출처-크레딧-수정) | 제목·자막·카드를 유지하며 문구·모양·출력 시간 설정. 최대 100 UTF-16 코드 단위; 자막 파일에는 포함되지 않음. |
| 문구 좌표 지정 | 제목·크레딧·공통 자막·선택 카드 → **위치…** | 가로/세로 백분율을 입력해 함께 적용; 바꾸지 않은 축의 저장값 유지. |
| 카드 길이를 유지하며 시간 이동 | 선택한 카드 → **표시 시간 이동…** | **배속 후 출력 초**로 새 시작 입력; 양 끝을 함께 수정하는 한 번의 편집. |
| 시간별 카드 구성 | [`overlays.add`, `overlays.update`, `overlays.remove`](INTEGRATIONS.md#스크립트에-맞춰-카드-추가삭제) | 전체 프로젝트 교체 없이 ID별 작업. **배속 후** 출력 시간 사용. 뒤에 추가하며, `overlays.move` 또는 선택 카드의 **한 단계 앞으로 / 한 단계 뒤로**로 비활성·현재 시간 밖 카드를 포함한 저장 순서 한 칸, **맨 앞으로 / 맨 뒤로**로 끝까지 이동. 한 단계 실행 취소, 시간·본문 유지; 자막과의 층이 아닌 카드끼리 순서만 변경. |

<a id="duplicate-clip-range"></a>

**클립 범위 복제…**의 시작·끝 번호는 현재 선택한 한 클립으로 열립니다. 원래
묶음 바로 뒤에 순서대로 한 번 복제하며 첫 사본을 선택하고 시작으로 이동합니다.
한 번에 실행 취소할 수 있습니다. 전체 범위가 존재하고 결과가 1,000개 이하여야
하며, 범위·용량 오류는 부분 복제 없이 거절합니다. 취소 자체는 추가 편집을 만들지
않습니다. 원본 자막은 사본에서도 나타나고 타임라인 자막·오디오 오프셋 수치는
유지됩니다. 제목·크레딧·카드는 복제하지 않고 출력 길이에 비례해 시간을 한 번
조정합니다. 미디어 파일 복사나 여러 클립 선택 상태를 저장하는 기능은 아닙니다.

**위치…**는 렌더링된 글자 테두리가 아닌 레이어의 정규화된 기준 좌표를 편집합니다.
변경하는 제목 좌표는 가로 **5–95%**, 세로 **6–93%**이며 크레딧·공통 자막·카드는
각 축 **0–100%**입니다. 소수 입력을 허용하고 변경 축을 한 번에 적용·실행 취소하며
내용·시간·스타일은 유지합니다. 바꾸지 않은 축은 현재 편집 한도 밖의 가져온 제목
좌표라도 원래 저장값을 그대로 유지합니다. 취소·동일 값은 추가 편집이 없습니다.
좁은 화면에서도 패널에서 접근할 수 있습니다. 프로젝트·레이어·미디어가 바뀌면 다시
여세요. 유효한 복구 실패 상태의 메모리 편집은 설정 백업이 필요합니다. 레이어별 기준점과
글자 맞춤/위치 제한이 달라 시각적 중앙·픽셀 정렬·안전 영역 포함을 보장하지 않습니다.

**표시 시간 이동…** 대화상자의 **현재 위치를 시작값으로 입력**은 현재 재생 위치를 변속 후 출력 초로 환산해 초안과 계산된 끝값만 채웁니다. 검토 후 **이동**으로 적용하세요. 입력만으로 편집·정지·탐색·저장·기록이 발생하지 않으며 출력 범위를 넘는 카드는 자르지 않습니다.

예를 들어 0–3초 카드를 7–10초로 옮기려면 **표시 시간 이동…**에서 `7`을 입력하고
계산된 끝값을 확인한 뒤 **이동**을 누르세요. 길이·ID·겹침 순서·내용·스타일과 다른
카드는 유지합니다. 실제 변경 시 일시 정지하지만 현재 재생 위치는 유지하며 카드로
탐색하지 않습니다. 전체 구간이 출력 범위 안에 들어와야 하며 범위 밖이거나 너무 긴
카드는 자르지 않고 거절합니다. 취소·같은 시작값은 편집·정지·탐색·저장·기록을
만들지 않습니다. 카드·제목·크레딧의 시작/끝 입력은 저장된 소수를 두 자리로 반올림하지
않고 표시하며 0.1초 입력 격자 없이 소수를 받습니다. 미지정 제목/크레딧 끝은 빈 값/null을
유지하고 읽기 전용 요약은 반올림할 수 있습니다. 기존 편집 반영 시점·구간 검증은 바뀌지
않습니다. 소수 시간은 일반 부동소수점 정밀도이며 샘플 단위 정확도 보장은
아닙니다. 프로젝트·미디어·선택 카드가 바뀌면 다시 여세요. 유효한 설정을 읽은 복구
실패 상태에서는 메모리 편집만 가능하고 브라우저 저장은 막혀 있으므로 설정을 따로 백업하세요.

자막·카드의 시작/끝은 비워 둘 수 없습니다. 유효한 구간 안에서 `0`이나 소수 초를
명시적으로 입력하세요. 자막은 **배속 전** 원본/타임라인 초, 카드는 **배속 후** 출력 초를
쓰며, 선택 사항인 제목·크레딧 끝은 여전히 빈 값/null로 출력 끝까지 표시할 수 있습니다.

**클립 이동…**에서 1부터 클립 개수 사이의 위치를 입력하고 **이동**을 누르세요.
실제 이동은 한 번에 실행 취소할 수 있으며 선택이 이동한 클립을 따라가고 일시 정지 후
새 시작 위치로 탐색합니다. 기존 화살표도 같은 동작을 사용합니다. 해당 클립의 트림
초안은 유지하지만 다른 패널 초안까지 보존한다고 가정하지 마세요. 프로젝트·미디어·
선택이 바뀌면 다시 여세요. 원본 범위·저장된 자막/제목/카드 시간은 다시 쓰지 않으며
원본 자막의 파생 위치는 새 순서를 따르고 타임라인 자막은 절대 시간을 유지합니다.
복구 실패 후에도 유효한 설정을 읽었다면 메모리에서 이동할 수 있지만 브라우저 저장은
차단됩니다. 새로고침 전에 편집 설정 파일로 백업하세요.


**클립 범위 삭제…**는 연속된 한 범위를 삭제하며 다중 선택을 저장하는 기능은 아닙니다.
확정하면 범위 다음의 첫 생존 클립, 없으면 마지막 생존 클립을 선택하고 시작으로 탐색합니다.
원본 자막은 보존하고 타임라인 자막 시간·오디오 오프셋은 절대값을 유지합니다. 제목·
크레딧·시간별 카드의 출력 시간은 짧아진 타임라인에 비례해 조정됩니다. 구조 편집이므로
트림 초안은 초기화하지만 취소하면 유지합니다. 프로젝트·미디어·선택이 바뀌면 다시 여세요.
유효한 복구 실패 설정은 여전히 메모리 편집이며 브라우저 저장 대신 새로고침 전에
설정 파일을 백업해야 합니다.

**빈 구간만 유지…**는 모든 현재 클립의 원본 범위를 합친 뒤 전체 원본 길이에서 그
밖의 구간만 남깁니다. 12초 원본의 클립이 2–4·6–8초라면 결과는 0–2·4–6·8–12초이며,
현재 순서나 반복은 보존하지 않습니다. 원본 구간(페이지당 20개)·개수·배속 후 출력 길이를 검토해 확정하면
한 번에 실행 취소 가능한 교체로 첫 결과 클립을 선택하고 시작으로 탐색합니다.

남는 구간이 없거나, 양수 결과 구간 중 **0.1초 미만**이 있거나, 결과가 **1,000클립**을
넘으면 거절하며 작은 구간을 몰래 버리지 않습니다. 이 최솟값은 이 UI 동작의 조건이지
모든 가져온 프로젝트 클립의 조건은 아닙니다. 원본 자막 값은 유지되어 되살린 원본
구간에 자막이 다시 나타날 수 있습니다. 타임라인 자막·추가 오디오 오프셋은 절대값을
유지하고 제목·크레딧·카드 출력 시간은 새 길이에 비례 조정합니다. 무손실 렌더링이나
가역 기록이 아니므로 두 번 반전해 순서·반복을 복원하려 하지 말고 실행 취소/설정 백업을
사용하세요. 문맥이 바뀌면 다시 열고 유효한 복구 실패 편집도 새로고침 전 설정을 백업하세요.

## 개인정보와 제한사항

**미디어는 기기에 남지만, 완전한 오프라인 앱은 아닙니다.** 글꼴은 Google Fonts에서, 자동 자막 코드는 jsDelivr에서, 모델·런타임 파일은 Hugging Face와 관련 런타임 제공처에서 내려받습니다. 음성 인식은 브라우저 워커에서 실행됩니다. 외부 요청과 신뢰 경계는 [SECURITY.md](SECURITY.md)에 정리되어 있습니다.

| 입력·프로젝트 항목 | 최대 한도 |
| --- | --- |
| 영상 / 추가 오디오 | 500 MiB / 100 MiB |
| 프로젝트 설정 JSON 저장·복원 / SRT·VTT 입력 | 10 MiB / 2 MiB, UTF-8 |
| 클립 / 원본 자막 구간 | 1,000개 / 10,000개; 구간당 2,000 UTF-16 코드 단위 |
| 사용자 템플릿 / 시간별 문구 | 20개 / 12개 |

클립이 1,000개라면 다른 클립을 분할하기 전에 하나를 삭제하세요.

**검증 한도이며 메모리 여유나 코덱 지원을 보장하지 않습니다.** 브라우저 저장소는 백업이 아닙니다. 미디어와 설정을 따로 쓰므로 저장 실패 시 서로 맞지 않을 수 있습니다. 원본 미디어를 보관하고 프로젝트 JSON을 주기적으로 내보내세요.

**자동 자막:** 편집 길이가 짧아도 **원본 영상은 180초 이하여야** 합니다. 선택한 오디오는 최대 180초까지 처리합니다. 인식 결과·수동 화자·분할 추정 시간은 직접 검토하세요.

## 오디오와 영상 내보내기

<a id="audio-mix"></a>

**오디오에서 믹스 균형 맞추기:** 프로젝트와 파일 연결 상태에 따라 기존 두 프로젝트 볼륨을 한곳에서 조절합니다.

| 오디오 조절 | 범위 |
|---|---|
| **원본 영상 볼륨** | 영상 프로젝트에서 표시; 화면 패널의 기존 원본 볼륨과 같은 값 |
| **추가 오디오 볼륨** | 추가 오디오 파일이 연결되어 있을 때 표시 |

둘 다 0–100% 전체 볼륨이며 클립별 믹싱이나 새 음향 처리가 아닙니다. 영상 프로젝트라도 오디오 트랙이 있다는 뜻은 아닙니다. 녹화 믹스에 적용하는 값으로 아래의 세션 전용 미리보기 음소거와 구별하세요.

**마이크 녹음:** 실행 취소·다시 실행은 진행 중인 녹음을 멈추지 않습니다. 패널이 갱신되어도 오디오의 경과 시간과 **녹음 완료** 동작을 유지합니다. 마이크 권한을 기다리거나 녹음을 마무리·불러오는 동안에는 같은 버튼에 진행 상태를 표시하고 비활성화하여 새 녹음을 시작하지 않습니다.

**오디오 시작 위치:** 출력 영상 기준 초를 입력하고, 처음부터 시작하려면 `0`을
명시하세요. 비어 있거나 유효하지 않은 숫자 입력은 초안을 유지한 채 경고만 표시하며
오프셋·자막·편집 기록을 바꾸지 않습니다. 유효한 숫자의 기존 범위 보정과 타임라인
자막 이동 방식은 그대로이며, 어떤 자막이 추가 오디오를 따라가는지는 바꾸지 않습니다.
현재 오프셋이 편집 길이 안에 있을 때 수치가 같은 위치를 다시 입력하면 자막을 이동하거나
기록을 추가하거나 다시 실행 이력을 지우거나 저장을 예약하지 않습니다. 저장된 오프셋이
편집 길이 밖에 있으면 다시 확정할 때 기존처럼 범위를 보정합니다.

**추가 오디오를 불러오는 동안:** 성공 완료 시점에 **타이틀·연출·템플릿·화면** 패널이
열려 있으면 완료 처리 때문에 그 패널을 다시 만들고 미반영 입력을 지우지 않습니다.
**오디오·자막·미디어**는 새 원본에 맞게 계속 갱신합니다. 기존 일시 정지·타임라인/검사기
갱신·저장 규칙은 그대로이며 초안 자동 저장이나 실행 취소·프로젝트 교체를 넘는 보존은
추가하지 않습니다.

**미리보기 음소거는 무음 파일 설정이 아닙니다.** 스피커 버튼은 내보내기 중에도
듣는 소리만 끄며, 녹화 믹스는 프로젝트의 원본 볼륨·추가 오디오 볼륨을 따릅니다.
무음 믹스가 필요하면 **두 볼륨을 모두 0**으로 설정하세요. 음소거 선택은 출력·취소·
재시도 중 유지하지만 현재 세션에만 적용되고 새로고침하면 기본 음소거 해제로 돌아옵니다.
프로젝트에 저장되는 필드는 아닙니다.

### 녹화 옵션

**영상 내보내기:** 탭을 화면에 표시한 상태로 유지하세요. 숨겨지면 녹화가 취소됩니다. MP4/WebM 지원은 브라우저에 따라 다릅니다. 실시간 녹화의 목표는 30 fps이며 고정 프레임 레이트를 보장하지 않습니다. 과거 Chromium 4초 테스트는 평균 약 21.7 fps였으며 [측정 보고서](docs/BROWSER_QA.md)에 조건을 기록했습니다.

**다시 다운로드:** 완료 창이 열려 있는 동안 완성된 영상 한 개를 메모리에 보관하며, 다운로드 처리 오류가 나도 **다시 다운로드**할 수 있습니다. 다시 녹화하지 않고 같은 영상 데이터와 파일명을 사용하므로 이후 프로젝트 수정은 포함되지 않습니다. 같은 파일이 추가로 내려받아질 수 있으니 브라우저 다운로드 목록을 먼저 확인하세요. 창을 닫거나 다른 창으로 바꾸거나 새 내보내기를 시작하면 앱의 결과 참조를 해제합니다. 이미 전달한 다운로드 URL은 기존처럼 60초 후 정리합니다. 브라우저 다운로드 허용이나 디스크 저장 완료를 보장하지는 않습니다.

내보내기 창의 두 옵션은 열 때마다 기본으로 켜집니다. 시작 시 이번 요청의 선택을
고정하며 프로젝트 편집·저장·기록을 만들지 않습니다.

| 출력 옵션 | 끄면 달라지는 것 |
|---|---|
| **영상에 자막 포함** | Moment 대사 자막 레이어만 제외; 켜도 프로젝트에서 비활성화한 자막을 강제로 표시하지 않음 |
| **오디오 포함** | 무음 믹스를 녹음하는 대신 녹화 스트림에서 오디오 트랙 제외 |

오디오 포함 선택은 프로젝트 볼륨이나 미리보기 음소거·듣는 소리를 바꾸지 않습니다.
오디오 트랙을 유지한 무음 믹스가 필요하면 켠 채 두 프로젝트 볼륨을 0으로 설정하세요.
기존 오디오 준비·브라우저 코덱 검사는 그대로이므로 오디오 준비 오류를 우회하지는
않습니다. 새 영상을 녹화하려고 내보내기 설정을 다시 열면 두 옵션이 다시 켜집니다.
**다시 다운로드**는 원래 선택이 반영된 완성 파일을 그대로 사용합니다.

자막 포함 선택은 다음 출력에 적용됩니다.

| 출력 | 끄면 달라지는 것 |
|---|---|
| 녹화 영상 | 대사 자막 제외; 제목·크레딧·시간별 카드·원본 영상은 유지 |
| 출력 전후 일반 편집·PNG·템플릿 미리보기 | 변경 없음; 녹화 중 PNG 저장은 기존처럼 차단 |
| 녹화 중 미리보기 | 선택한 녹화 결과를 비추므로 자막 제외도 반영 |
| SRT/VTT 자막 파일 | 변경 없음; 자막 패널에서 별도 저장 |

원본 픽셀에 이미 있는 글자를 지우거나 MP4/WebM에 켜고 끄는 자막 트랙을 넣는 기능이
아닙니다. CLI/MCP `render.plan`에는 새 옵션이 없으며 여전히 인코딩이 아닌 계획입니다.

## 저장소와 파일 형식

<details>
<summary>저장소·대기 중인 가져오기·자막 생성 충돌</summary>

**저장:** 미디어는 IndexedDB, 편집 상태는 localStorage에 따로 저장하므로 저장 실패 시 서로 맞지 않는 상태가 남을 수 있습니다. 현재 브라우저와 출처에 종속되므로 호스트나 포트가 바뀌면 다른 저장소를 사용합니다. 브라우저 데이터 삭제·시크릿 모드·저장 공간 부족으로 작업이 사라질 수 있습니다. 클라우드 동기화나 원격 백업은 없습니다.

**가져오기 대기 중:** 파일을 읽거나 적용을 기다리는 동안 프로젝트가 바뀌면 가져오기를 거부합니다. 현재 프로젝트에 적용하려면 파일을 다시 선택하세요. 다른 JSON/SRT/VTT를 선택하면 새 파일이 실패해도 이전 대기 요청은 취소됩니다. 이 검사는 적용된 프로젝트 상태를 보호하며, 아직 적용하지 않은 입력란 초안은 포함하지 않습니다.

**자막 생성 중:** 원본 미디어·기존 자막이 바뀌거나 프로젝트가 교체되면 결과를 적용하지 않습니다. 추가 오디오 결과는 오프셋·편집 길이도 같아야 적용됩니다. 색상 등 외형 편집은 계속 사용할 수 있습니다.

**자막** 패널이 열려 있을 때 행의 문구·시간·화자·강조 단어에 미확정 입력이 있거나 패널 안에서 조합 중이면 결과 적용을 거절합니다. 충돌·실패·취소 시 현재 입력란은 유지하며 초안을 자동 확정하거나 저장하지 않습니다. 패널을 떠나거나 교체한 뒤의 입력 보존, 충돌 감지 시 모델 연산 중단까지 보장하지는 않습니다.

새 인식 결과로 현재 자막을 교체하려는 경우에만 **자동 자막 생성**을 다시 선택하세요. 보관한 결과를 적용하는 것이 아니라 인식을 다시 실행하며, 이미 확정한 교정 내용도 교체될 수 있습니다.

</details>

<details>
<summary>UTF-8·자막 형식·시간 규칙</summary>

**텍스트 가져오기:** 프로젝트 JSON과 SRT/VTT는 UTF-8로 저장하세요. 파일 시작의 UTF-8 BOM은 지원합니다. 자막의 LF·CRLF·CR 줄바꿈은 본문 줄 구분을 유지하며 LF로 정규화합니다. 잘못된 UTF-8은 현재 프로젝트·자막을 교체하지 않고 거부하며, 다른 인코딩을 자동으로 추측하거나 변환하지 않습니다.

**자막 파일:** 자막 패널에서 **SRT**, **VTT**, **TXT**, **검토용 TXT** 형식을 선택하고 하나의 저장 버튼을 사용하세요. 기본은 SRT이며 페이지를 옮겨도 선택을 유지합니다.

**일반 WebVTT:** **VTT**를 선택하거나 CLI/MCP 내보내기에 `format: "vtt"`를 전달하세요. `format` 생략 시 기존처럼 SRT를 출력하며 `.vtt` 확장자만으로 형식이 바뀌지 않습니다. VTT는 `WEBVTT` 헤더와 점으로 구분한 밀리초를 사용하며 편집 시간과 문구 이스케이프 규칙은 동일합니다. 꾸밈 스타일·영역·화자 메타데이터는 내보내지 않고 NUL 문자는 거부합니다. 자막이 없으면 CLI/MCP는 `WEBVTT\n\n`을 반환하며 브라우저는 빈 자막 파일을 내려받지 않습니다.

**텍스트 출력 선택:**

| 형식 | 받는 내용 |
|---|---|
| **TXT** | 기존 자막 문단, 시간·화자 이름 없음 |
| **검토용 TXT** | `.review.txt`에 배속 후 출력 초·명시적으로 배정된 비어 있지 않은 화자 이름·본문; 반복/겹침 구간은 각각 나열 |

검토용 표제는 UI 언어를 따르며 작성된 이름·문구는 번역하지 않습니다. 사람을 위한 검토 목록이지 가져오기 형식·렌더링 가시성 보장·음성 검증 녹취·프로젝트 백업이 아닙니다. 두 형식 모두 LF·BOM 없는 UTF-8이며 빈 결과는 내려받지 않습니다. 사용된 이름도 최종 2 MiB에 포함하고 NUL은 거절합니다. [CLI/MCP 선택과 한도](INTEGRATIONS.md#자막-검토용-txt)

**일반 TXT:** 클립·반복·원본/타임라인 자막·배속을 반영한 출력 순서로 파생 자막당 한 문단을 저장합니다. 반복·분할 클립은 같은 단어를 반복할 수 있어 중복 제거·단어별 정확한 녹취록이 아닙니다. 시간·ID·화자·제목·카드·스타일은 포함하지 않습니다. `<>&` 리터럴·공백·여러 줄 문구를 유지하고 줄바꿈은 LF, 구간 사이는 빈 줄, 마지막은 줄바꿈으로 저장합니다. 빈 줄·밀리초 미만 구간도 허용하지만 NUL은 거부합니다. 자막이 없으면 `""`를 반환합니다. SRT/VTT 가져오기로 TXT를 불러오거나 시간을 복원할 수 없습니다.

**UTF-8 출력 경계:** 출력할 UTF-16 단독 서로게이트는 `U+FFFD`로 몰래 바꾸지 않고 거절합니다. SRT/VTT/TXT·검토용 TXT의 자막 문구, 검토에 사용한 화자 이름, 그래픽 목록에 출력하는 작성 필드가 대상입니다.

잘려서 제외된/범위 밖 자막·사용하지 않는 이름·무관한 그래픽은 범위 지정 자막 출력을 막지 않습니다. Unicode 정규화·자동 복구는 하지 않으며 올바른 쌍의 이모지·결합 문자·직접 작성한 `U+FFFD`는 이 검사로 바뀌지 않습니다.

모델·가져오기 검증은 그대로이며 프로젝트 JSON은 복구를 위해 이스케이프한 코드 단위를 유지합니다. 의도한 문구를 수정한 뒤 재시도하세요.

이 자막 Unicode 오류의 CLI/MCP `error.path`는 `project.captions[2].text` 또는 `project.speakerLabels[1]`처럼 0부터 세는 작성 필드를 가리킵니다. 자막 경로는 범위 선택·정렬·클립 반복 후에도 출력 자막 번호가 아닌 원래 프로젝트 인덱스를 유지합니다. 편집 후에는 인덱스가 달라질 수 있으므로 현재 데이터를 다시 읽고 해당 필드만 수정하세요.

**SRT/VTT 문구:** SRT/VTT/TXT 모두 NUL(`U+0000`)을 자동 제거하지 않고 거절합니다. 해당 문자를 수정/제거한 뒤 다시 출력하세요. 프로젝트 JSON은 원문을 유지하며 실패 시 기존 출력 파일을 덮어쓰지 않습니다. 빈 줄은 자막 구간을 구분합니다. 빈 자막이나 자막 안의 빈 줄은 문단을 삭제하거나 시간을 다시 배정하지 않고 내보내기를 거부합니다. SRT/VTT를 저장하려면 빈 줄을 제거하세요. JSON은 원문을 유지합니다. 일반적인 여러 줄 자막은 지원하며 CRLF/CR은 LF로 정규화합니다. 재생기마다 마크업 지원이 달라 모든 재생기와의 호환성을 보장하지 않습니다.

**SRT/VTT 시간:** 자르기·배속 적용 후 밀리초로 반올림합니다. 반올림한 시작과 끝이 같아지면 내보내기를 거부하므로 구간이나 배속을 조절하세요. 구간을 임의로 늘리거나 삭제·이동하지 않으며 프로젝트에는 정밀한 원래 시간이 남습니다.

</details>

<details>
<summary>편집 후 자막 예산과 긴 자막 분할</summary>

**편집 후 자막 한도:** 타임라인 자막 표시와 SRT/VTT/TXT는 반복 클립을 포함해 최대 10,000개, 원문 합계 UTF-8 2 MiB를 지원합니다. 각 자막 파일은 이스케이프·시간·구분자·VTT 헤더(해당 시)·실제 BOM까지 포함해 별도로 2 MiB 이하이어야 합니다. 브라우저 SRT에는 BOM을 넣고 브라우저 VTT/TXT와 CLI/서비스 출력에는 넣지 않습니다. 이전 프로젝트도 한도 초과 시 표시·자막 출력 전체를 거절하며 일부만 출력하지 않습니다. 반복 클립이나 자막을 줄이면 복구됩니다. 원본 자막 편집·JSON·실행 취소·저장은 유지됩니다. 이 한도가 화면 응답성이나 메모리 여유를 보장하지는 않습니다.

**긴 자막 분할:** 12/18/24자 목표와 시간 추정 가중치는 문자소 묶음(grapheme cluster)을 셉니다. 결합 문자·연결된 이모지를 함께 유지하고 Unicode 정규화는 하지 않습니다. 경계 공백은 묶음 단위로 제거합니다. 네이티브 `Intl.Segmenter`가 없으면 오류를 표시하고 자막을 유지합니다. 별도의 입력 한도 2,000 UTF-16 코드 단위와 UTF-8 바이트 예산도 적용됩니다. 분할은 런타임의 Unicode 데이터에 따라 다르며 추정 시간은 음성과 비교해 검토해야 합니다.

</details>

## 문제 해결

- **화면이 열리지 않아요:** `npm start`가 실행 중인지 확인하세요. 4173 포트를 이미 사용 중이라면 다른 서버를 종료하거나 `PORT` 환경 변수를 빈 포트로 설정한 뒤, 서버에 표시된 주소로 접속하세요.
- **영상이 열리지 않거나 내보낼 수 없어요:** H.264 MP4 또는 WebM 원본과 필요한 미디어 API를 지원하는 다른 브라우저로 시도하세요. MOV 지원 여부는 내부 코덱에 따라 달라집니다. 내보내기 오류가 나면 720p로도 시도해 보세요.
- **자동 자막이 실패해요:** 음성이 있는 짧은 원본을 사용하고 선택한 언어와 네트워크 연결을 확인하세요. SRT/VTT 가져오기나 직접 편집으로도 작업할 수 있습니다. 기본 샘플에는 인식할 음성이 없습니다.
- **저장한 작업이 보이지 않아요:** 같은 브라우저·호스트·포트로 접속했는지 확인하세요. 다른 브라우저에서 JSON을 복원하려면 원본 영상과 추가 오디오를 먼저 연결한 뒤 **프로젝트 파일 → 편집 설정 불러오기**를 선택하세요.
- **복원에 실패했어요:** 기존 데이터를 보호하기 위해 프로젝트 저장·미디어 교체·녹음·초기화를 중지합니다. 읽을 수 있었던 설정은 메모리에서 편집하고 **프로젝트 파일 → 편집 설정 저장**으로 내보낼 수 있습니다. 변경사항은 브라우저에 저장되지 않으므로 새로고침 전에 내보내세요. 새로고침은 읽기를 재시도할 뿐, 누락된 미디어나 코덱 문제를 해결하지는 않습니다. 미저장 편집의 종료 경고는 브라우저에 따라 나타나지 않을 수 있습니다. [이번 탭에서만 원본 연결](#이번-탭에서만-원본-다시-연결)로 저장소를 복구하지 않고 미리보기·출력을 사용할 수 있습니다.

- **저장한 템플릿을 읽을 수 없어요:** 잘못된 사용자 템플릿·즐겨찾기는 해당 세션에서 격리하며, 원본 저장값을 보호하기 위해 라이브러리 저장·삭제·즐겨찾기 변경을 차단합니다. 프로젝트가 정상적으로 열리면 기본 템플릿과 프로젝트 편집은 계속 사용할 수 있습니다. 새로고침은 읽기를 재시도할 뿐 라이브러리를 복구하지 않습니다. 항목을 자동으로 삭제하거나 일부만 복원하지 않습니다.

### 이번 탭에서만 원본 다시 연결

복원이 실패했어도 **유효한 프로젝트 설정을 읽었다면**, **프로젝트 파일 → 원본 파일
다시 연결**을 여세요. 필요한 원본 영상·추가 오디오를 모두
선택하고 이 프로젝트의 원본임을 명시적으로 확인한 뒤 **이번 탭에 연결**을 누릅니다.
임시 검사뿐 아니라 편집기의 실제 미디어 요소까지 읽기를 마쳐야 재생 기능을 허용합니다.

| 연결 성공 후 | 경계 |
|---|---|
| 미리보기·탐색·영상 출력·미리보기 PNG | 이번 탭에서 사용 가능; 자동 재생하지 않음 |
| 메모리 편집·실행 취소·설정 백업 | 계속 가능; 새로고침 전에 설정 파일 다운로드 |
| 브라우저 저장·자동 저장·일반 가져오기·초기화·녹음·음성 인식 | 여전히 차단; 저장 오류·상태를 해제하지 않음 |
| 새로고침 | 원본 파일을 다시 제공해야 함; 저장소 복구 기능 아님 |

파일 이름은 일치해야 하지만 **이름·길이 일치는 같은 원본이라는 증거가 아닙니다**.
영상은 저장된 길이와 모든 클립을 포함해야 하며 더 짧으면 거절합니다. 저장된 길이를
넘는 차이는 최대 0.05초입니다. 추가 오디오는 유한한 양수 길이를 확인하지만 저장된
오디오 길이와 비교할 수는 없습니다. 기존 영상 500 MiB·오디오 100 MiB 한도가 유지됩니다.
실제 원본을 보관하세요. 연결 자체는 프로젝트 JSON·기록·IndexedDB·localStorage를
바꾸지 않으며, 프로젝트/미디어 조건 변경·실패·취소로 오래된 재생 권한을 부여하지 않습니다.

## 개발과 기여

```sh
npm test
node examples/use-editor-service.mjs
node examples/use-mcp-client.mjs
```

`npm test`는 문법 검사, 편집기 회귀 검사, CLI 파일 입출력, 프로젝트 검증, MCP 수명주기·스키마·요청 격리·대화형 클라이언트 예제, 자막 파서, 로컬 HTTP 서버 테스트를 실행합니다. CI는 Linux의 Node 20/22/24와 Windows의 Node 24에서 실행하도록 구성되어 있으며, 상단 배지에서 실제 결과를 확인할 수 있습니다.

저장 테스트는 합성 트랜잭션 오류를 주입해 취소·대기 중인 재시도·저장 상태 표시를 확인합니다. 실제 브라우저의 용량 초과, 저장소 축출, 비정상 종료 후 복구는 검증하지 않습니다.

`dist/`는 빌드 산출물이 아니라 **직접 관리하는 앱 소스**입니다.

```text
dist/               브라우저 UI, 합성, 자막, 로컬 저장
  core/             DOM 없이 동작하는 프로젝트 모델·검증·편집 명령
  integration/      편집 서비스와 MCP 어댑터
cli/                Node.js 프로젝트·자막 CLI, stdio MCP 세션과 전송
scripts/            로컬 미리보기 서버
examples/           명령 인자와 실행 가능한 서비스/MCP 예시
tests/              Node 테스트
verify.mjs          편집기 회귀 검사
```

코드 기여와 버그 신고는 [CONTRIBUTING.md](CONTRIBUTING.md), 예정된 작업은 [ROADMAP.md](ROADMAP.md), 취약점 비공개 제보는 [SECURITY.md](SECURITY.md)를 확인하세요.

[실제 브라우저 검증 보고서](docs/BROWSER_QA.md)에는 Chromium/macOS에서의 영상 업로드·자막·저장 복원·MP4 출력 결과와 성능 한계가 있습니다. [QA.md](QA.md)는 회귀 검사 범위를 설명합니다. 자동 테스트는 필요한 곳에서 모의 브라우저 API를 사용하므로 마이크·음성 인식·여러 브라우저의 호환성을 보장하지 않습니다.
