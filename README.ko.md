# Moment · 모먼트 쇼츠 스튜디오

**영상 편집부터 자막, 내보내기까지. 내 브라우저에서 만드는 쇼츠.**

[English](README.md) · **한국어**

[![CI](https://github.com/bugtype/moment-shorts-cut/actions/workflows/ci.yml/badge.svg)](https://github.com/bugtype/moment-shorts-cut/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Moment는 한국어 UI를 제공하는 로컬 중심 영상 편집기입니다. 원본을 앱 서버에 업로드하지 않고, 필요한 장면을 자르고 템플릿·자막·내레이션을 더해 쇼츠로 내보낼 수 있습니다. 계정이나 API 키는 필요하지 않습니다.

자동화를 위한 공통 편집 명령, 프로젝트 JSON/SRT CLI, MCP 어댑터도 제공합니다. 아직 초기 단계의 프로젝트이므로 사용하려는 브라우저와 코덱에 대한 [검증 결과와 남은 범위](docs/BROWSER_QA.md)를 확인해 주세요.

## 빠른 시작

**Git과 Node.js 20 이상(npm 포함)**이 필요합니다. npm 의존성 설치나 별도 빌드 과정은 없습니다.

```sh
git clone https://github.com/bugtype/moment-shorts-cut.git
cd moment-shorts-cut
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)을 여세요. 첫 화면에는 **12초 모션 그래픽 샘플**이 있어 원본 영상 없이도 템플릿과 내보내기를 체험할 수 있습니다. 샘플 자막은 편집용 예시이며, 샘플에는 자동 인식할 음성이 없습니다.

편집하는 동안 서버를 켜두고, 종료할 때는 `Ctrl+C`를 누르세요. 서버는 `127.0.0.1`에서 `dist/`만 제공합니다. JavaScript 모듈·워커·브라우저 저장소를 사용하므로 `dist/index.html`을 더블클릭하지 말고 위 HTTP 주소로 접속하세요.

### 첫 쇼츠 만들기

1. **미디어:** 영상을 업로드하거나 샘플로 시작합니다. **화면**에서 9:16·1:1·16:9 비율과 구도를 맞추고, 타임라인에서 필요한 구간을 자르거나 나누고 순서를 바꿉니다.
2. **템플릿:** 원하는 구성을 고릅니다. **스타일만 적용**은 작성한 문구를 유지합니다. 예시 구성까지 적용하면 제목·크레딧·시간별 문구가 교체되며, 영상과 대사 자막은 유지됩니다.
3. **자막:** SRT/VTT를 불러오거나 직접 작성하고, 음성이 있는 원본은 로컬 자동 자막을 생성합니다. 문구와 타이밍을 확인하고 **타이틀·연출**에서 제목과 시간별 문구를 꾸밉니다.
4. **오디오:** 음성 파일을 추가하거나 마이크 권한을 허용해 내레이션을 녹음합니다. 시작 위치와 볼륨을 원본 음성에 맞춰 조절합니다.
5. **내보내기:** 지원되는 MP4/WebM 형식과 720p·1080p를 선택합니다. **완료될 때까지 탭을 화면에 표시한 상태로 유지**하고, 다운로드한 영상을 재생해 결과를 확인합니다.

**사용 가이드 → 편집 설정 저장**으로 프로젝트 JSON을 백업하세요. **JSON에는 미디어 파일이 포함되지 않으므로** 원본 영상과 오디오도 별도로 보관해야 합니다.

## 주요 기능

- **타임라인 편집:** 구간 자르기·분할·순서 변경·삭제, 배속, 위치·확대 조절, 실행 취소·다시 실행.
- **템플릿과 타이포그래피:** 기본 구성 10개, 검색·즐겨찾기, 브라우저에 저장하는 사용자 템플릿 최대 20개, 제목·크레딧 스타일, 시간별 문구 최대 12개.
- **자막:** SRT/VTT 가져오기, 편집 구간과 배속을 반영한 SRT 저장, 강조어, 직접 지정하는 화자 2명, 등장 효과, 글자 수로 시간을 추정하는 긴 자막 분할.
- **오디오와 음성 인식:** 원본 볼륨, 추가 오디오 파일 또는 마이크 녹음, Transformers.js 3.8.1과 `Xenova/whisper-tiny`를 이용한 기기 내 자동 자막.
- **영상 효과:** 느린 줌, 클립 경계의 검정 페이드·플래시, 밝기·대비·채도·비네트, 선택형 진행 막대.
- **로컬 저장과 출력:** 브라우저 저장소, 프로젝트 JSON 가져오기·내보내기, Canvas와 Web Audio로 합성한 결과의 MediaRecorder 출력.

기본 템플릿은 리뷰 스토리, 강한 첫 문장, 브이로그, 설명, 인터뷰, 레시피, 랭킹, 제품 리뷰, 퀴즈, 시네마틱 구성을 제공합니다. 각 템플릿은 움직이는 샘플로 미리 볼 수 있습니다. 퀴즈 선택지와 카운트다운은 영상에 포함되는 그래픽이며 클릭형 투표가 아닙니다.

## CLI와 외부 연동

CLI는 **프로젝트 편집 설정과 자막**을 다룹니다. 저장소 루트에서 실행하세요.

```sh
# 샘플 프로젝트 생성
node cli/moment.mjs init --out project.json

# 저장소에 포함된 설명형 템플릿 적용
node cli/moment.mjs exec template.apply --project project.json --args-file examples/explainer.json --out edited.json

# 편집 구간과 배속을 반영한 자막 출력
node cli/moment.mjs exec captions.export --project edited.json --out captions.srt

# 명령 목록과 입력 스키마 확인
node cli/moment.mjs commands
```

기존 출력 파일은 보호되며, 교체하려면 `--overwrite`를 명시해야 합니다. `exec` 명령에 `--dry-run`을 추가하면 출력 파일을 쓰지 않고 결과를 확인합니다. 입력 JSON은 10 MB까지 지원합니다.

편집기 페이지에서 `window.moment`를 호출하거나 MCP 도구 어댑터를 자체 호스트에 연결할 수도 있습니다. 로컬 서비스·어댑터 예시는 `node examples/use-editor-service.mjs`로 실행합니다.

**CLI는 영상을 인코딩하지 않습니다.** `render.plan`은 MP4가 아닌 출력 계획을 반환합니다. MCP 어댑터에는 실행 중인 서버, 전송 계층, 인증이 포함되지 않습니다. 명령 규격, 자막의 시간 기준, 원본 재연결, 호스트의 책임은 [INTEGRATIONS.md](INTEGRATIONS.md)를 참고하세요.

## 개인정보와 제한사항

**미디어는 기기에 남지만, 완전한 오프라인 앱은 아닙니다.** 글꼴은 Google Fonts에서, 자동 자막 코드는 jsDelivr에서, 모델·런타임 파일은 Hugging Face와 관련 런타임 제공처에서 내려받습니다. 음성 인식은 브라우저 워커에서 실행됩니다. 외부 요청과 신뢰 경계는 [SECURITY.md](SECURITY.md)에 정리되어 있습니다.

- **저장:** 미디어는 IndexedDB, 편집 상태는 localStorage에 따로 저장하므로 저장 실패 시 서로 맞지 않는 상태가 남을 수 있습니다. 현재 브라우저와 출처에 종속되므로 호스트나 포트가 바뀌면 다른 저장소를 사용합니다. 브라우저 데이터 삭제·시크릿 모드·저장 공간 부족으로 작업이 사라질 수 있습니다. 클라우드 동기화나 원격 백업은 없습니다.
- **입력 한도:** 영상 500 MB, 추가 오디오 100 MB, 프로젝트 JSON 10 MB, SRT/VTT 2 MB 이하입니다. 자막은 최대 10,000개, 구간당 2,000자입니다. 이 한도가 기기의 메모리 여유나 코덱 호환성을 보장하지는 않습니다.
- **텍스트 가져오기:** 프로젝트 JSON과 SRT/VTT는 UTF-8로 저장하세요. 파일 시작의 UTF-8 BOM은 지원합니다. 자막의 LF·CRLF·CR 줄바꿈은 본문 줄 구분을 유지하며 LF로 정규화합니다. 잘못된 UTF-8은 현재 프로젝트·자막을 교체하지 않고 거부하며, 다른 인코딩을 자동으로 추측하거나 변환하지 않습니다.
- **가져오기 대기 중:** 파일을 읽거나 적용을 기다리는 동안 프로젝트가 바뀌면 가져오기를 거부합니다. 현재 프로젝트에 적용하려면 파일을 다시 선택하세요. 다른 JSON/SRT/VTT를 선택하면 새 파일이 실패해도 이전 대기 요청은 취소됩니다. 이 검사는 적용된 프로젝트 상태를 보호하며, 아직 적용하지 않은 입력란 초안은 포함하지 않습니다.
- **자막 생성 중:** 원본 미디어·기존 자막이 바뀌거나 프로젝트가 교체되면 결과를 적용하지 않습니다. 추가 오디오의 오프셋·편집 길이가 바뀐 경우도 다시 생성하세요. 색상 등 외형 편집은 계속 사용할 수 있습니다. 적용된 편집만 보호하며, 미적용 입력란 초안이나 충돌 시 모델 연산 중단까지 보장하지는 않습니다.
- **편집 후 자막 한도:** 타임라인 자막 표시와 SRT는 반복 클립을 포함해 최대 10,000개, 원문 합계 UTF-8 2 MiB를 지원합니다. SRT 파일은 이스케이프·시간·구분자·실제 BOM까지 포함해 별도로 2 MiB 이하이어야 합니다. 브라우저는 BOM을 넣고 CLI/서비스는 넣지 않습니다. 이전 프로젝트도 한도 초과 시 표시·SRT 전체를 거절하며 일부만 출력하지 않습니다. 반복 클립이나 자막을 줄이면 복구됩니다. 원본 자막 편집·JSON·실행 취소·저장은 유지됩니다. 이 한도가 화면 응답성이나 메모리 여유를 보장하지는 않습니다.
- **자동 자막:** 편집한 길이가 짧더라도 **원본 영상이 180초 이하여야** 합니다. 선택한 오디오는 최대 180초까지 처리합니다. 인식 결과는 직접 검토해야 하며, 화자는 수동 지정하고 분할 자막의 시간은 추정합니다.
- **내보내기:** 실시간으로 녹화하며 탭이 숨겨지면 취소됩니다. MP4/WebM 코덱 지원은 브라우저마다 다릅니다. 캡처 목표는 30 fps이지만 **고정 프레임 레이트를 보장하지 않습니다.** 문서에 기록된 Chromium의 4초 영상 테스트는 평균 약 21.7 fps였습니다.
- **편집 구조:** 원본 영상 1개, 영상 트랙 1개, 추가 오디오 파일 또는 녹음 1개를 사용합니다. 페이드는 클립 경계의 효과이며 두 클립을 겹치는 크로스 디졸브는 지원하지 않습니다.

### 문제 해결

- **화면이 열리지 않아요:** `npm start`가 실행 중인지 확인하세요. 4173 포트를 이미 사용 중이라면 다른 서버를 종료하거나 `PORT` 환경 변수를 빈 포트로 설정한 뒤, 서버에 표시된 주소로 접속하세요.
- **영상이 열리지 않거나 내보낼 수 없어요:** H.264 MP4 또는 WebM 원본과 필요한 미디어 API를 지원하는 다른 브라우저로 시도하세요. MOV 지원 여부는 내부 코덱에 따라 달라집니다. 내보내기 오류가 나면 720p로도 시도해 보세요.
- **자동 자막이 실패해요:** 음성이 있는 짧은 원본을 사용하고 선택한 언어와 네트워크 연결을 확인하세요. SRT/VTT 가져오기나 직접 편집으로도 작업할 수 있습니다. 기본 샘플에는 인식할 음성이 없습니다.
- **저장한 작업이 보이지 않아요:** 같은 브라우저·호스트·포트로 접속했는지 확인하세요. 다른 브라우저에서 JSON을 복원하려면 원본 영상과 추가 오디오를 먼저 연결한 뒤 사용 가이드에서 편집 설정을 불러오세요.
- **복원에 실패했어요:** 기존 데이터를 보호하기 위해 프로젝트 저장·미디어 교체·녹음·초기화를 중지합니다. 읽을 수 있었던 설정은 메모리에서 편집하고 **사용 가이드 → 편집 설정 저장**으로 내보낼 수 있습니다. 변경사항은 브라우저에 저장되지 않으므로 새로고침 전에 내보내세요. 새로고침은 읽기를 재시도할 뿐, 누락된 미디어나 코덱 문제를 해결하지는 않습니다. 미저장 편집의 종료 경고는 브라우저에 따라 나타나지 않을 수 있습니다.

## 개발과 기여

```sh
npm test
node examples/use-editor-service.mjs
```

`npm test`는 문법 검사, 편집기 회귀 검사, CLI 파일 입출력, 프로젝트 검증, MCP 요청 격리, 자막 파서, 로컬 HTTP 서버 테스트를 실행합니다. CI는 Linux의 Node 20/22/24와 Windows의 Node 24에서 실행하도록 구성되어 있으며, 상단 배지에서 실제 결과를 확인할 수 있습니다.

저장 테스트는 합성 트랜잭션 오류를 주입해 취소·대기 중인 재시도·저장 상태 표시를 확인합니다. 실제 브라우저의 용량 초과, 저장소 축출, 비정상 종료 후 복구는 검증하지 않습니다.

`dist/`는 빌드 산출물이 아니라 **직접 관리하는 앱 소스**입니다.

```text
dist/               브라우저 UI, 합성, 자막, 로컬 저장
  core/             DOM 없이 동작하는 프로젝트 모델·검증·편집 명령
  integration/      편집 서비스와 MCP 어댑터
cli/                프로젝트 JSON/SRT용 Node.js CLI
scripts/            로컬 미리보기 서버
examples/           명령 인자와 실행 가능한 연동 예시
tests/              Node 테스트
verify.mjs          편집기 회귀 검사
```

코드 기여와 버그 신고는 [CONTRIBUTING.md](CONTRIBUTING.md), 예정된 작업은 [ROADMAP.md](ROADMAP.md), 취약점 비공개 제보는 [SECURITY.md](SECURITY.md)를 확인하세요.
