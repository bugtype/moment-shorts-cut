## 문구 찾기와 바꾸기

- **반복 문구 교정.** **모두 바꾸기** · API 계약 [`captions.text.replace`](../INTEGRATIONS.md#자막-문구-일괄-교정) — 대소문자를 구분하는 일반 문자열, 겹치지 않는 일치만 처리. 정규식·Unicode 정규화 없음. 시간·화자·키워드·순서 유지. 빈 문구나 너무 긴 결과는 전체 거절. 브라우저 UI에서 일치 횟수 미리보기·한 단계 실행 취소.

- **일치 문구별 검토.** 브라우저 이전·다음 검색 — 같은 행의 여러 일치·잘라낸 범위 밖 자막도 포함해 일치마다 순환; 해당 페이지와 정확한 문구를 선택. 현재/전체는 행 수가 아닌 일치 횟수. 탐색만으로 재생 이동·편집·저장 없음.

- **한 일치만 바꾸기.** 검색 결과 선택 후 **선택한 일치 바꾸기** — 선택 문자열만 한 번에 실행 취소 가능한 수정; 시간·메타데이터 유지. 대체 문구 선택 후 다음은 그 뒤에서 계속. 동일 대체는 변경 없음, 빈/너무 긴 결과 거절. 미적용 행 편집을 마치고 오래된 일치는 다시 선택하며 덮어쓰지 않음.

- **작성 행 범위 안에서 교정.** 검색·대체 문구 입력 후 **범위 내 바꾸기…** — 가져온 리터럴 문구와 **1부터 시작하는** 양끝 포함 범위를 확인(기본: 선택한 일치의 행, 없으면 현재 페이지 첫 행 하나). 범위 내 일치/변경 개수를 보고 한 번에 실행 취소 가능한 교정 확정. 범위 밖·시간·메타데이터 유지, 지속 선택 아님; 개별/전체 교정·검색 이동은 별도.

- **줄바꿈을 포함해 찾기·바꾸기.** 두 줄 검색·대체 입력란 — 실제 줄바꿈을 입력하거나 붙여넣으세요. `\n`은 역슬래시와 n 그대로이며 줄바꿈으로 해석하지 않습니다. 대소문자 구분·비중첩·정규식 없는 일치와 시간·메타데이터 보존은 그대로입니다.

## 자막 한 행 분할·합치기

- **자막 하나를 커서에서 분할.** [`captions.split`](../INTEGRATIONS.md#자막-하나를-커서-위치에서-분할) 또는 행의 분할 동작 — 문구·메타데이터 유지. 문자소 수로 시간을 추정하며 음성 정렬 아님. 이모지·결합 문자 내부는 분할 불가. 긴 자막 전체 분할과 별도.

- **인접 자막 합치기.** [`captions.merge`](../INTEGRATIONS.md#인접한-자막-합치기) 또는 행의 **다음 자막과 합치기** — 페이지와 무관하게 다음 저장 행과 병합. 시간 기준·화자·키워드가 같고 시간이 순서대로 겹치지 않아야 함. 사이 공백에도 합친 문구 표시. UI에서는 한 번에 실행 취소.

## 키워드 강조 지우기

- **키워드 강조 지우기.** **글자 → 대사 → 키워드 강조 지우기…** 후 확인 — 공통·모든 자막의 강조 단어만 한 단계 실행 취소 가능한 수정으로 지웁니다. 본문·시간·화자·강조 박스 스타일은 유지합니다. 취소·이미 빈 상태는 추가 편집 없음; 내용이 바뀌면 다시 열어 확인하세요.

<a id="save-excerpt"></a>

## 자막 일부 저장

**자막 일부 저장:** 기존 한 번의 저장은 **전체 자막**을 유지하세요. 형식 옆에서 **작성 행 범위…**를 선택하고 **저장**을 누르면 양 끝을 포함하는 **1부터 시작하는 작성 행**을 입력해 다시 저장할 수 있습니다. 두 입력은 현재 페이지 첫 행으로 시작할 뿐 페이지 선택이 아닙니다.

SRT·VTT·TXT·검토 TXT는 전체 출력 시간·반복·잘린 자막 제외 규칙을 유지하며 시간을 0으로 재설정하지 않습니다. 파일명에는 `.rows-FIRST-LAST`가 붙습니다. 빈 출력·오류는 창을 유지합니다.

프로젝트 편집·탐색·정지·설정 저장·실행 취소 기록은 바꾸지 않습니다. 공유 전 문구와 화자 이름을 검토하세요.

<a id="view-in-video"></a>

## 영상에서 자막 찾기

자막 행의 **영상에서 보기**는 해당 시간 위치로 일시 정지·이동하며 편집·저장·실행 취소
기록·자동 재생을 만들지 않습니다. 원본 구간 반복 시 페이지당 20개 위치에서 선택합니다
(최대 1,000개 클립). 표시 시간은 배속 후 출력 기준이며 잘려 나간 자막은 안내만
표시합니다. 프로젝트·미디어가 바뀌면 다시 여세요. 시간 위치 탐색이지 화면 표시
보장은 아닙니다. 자막 비활성화·겹침 우선순위로 문구가 안 보일 수 있고 원본 프레임
단위 정확도도 보장하지 않습니다.

<a id="review-timing"></a>

## 자막 시간 검토

**자막 시간 겹침**은 발생 순서대로 최대 20개를 표시합니다. 관련 자막 버튼은 탐색 없이
원본 행으로 초점을 옮기며 **구간 보기**는 겹친 시간으로 일시 정지·이동한 뒤 첫 관련
행에 초점을 옮기고 자동 재생하지 않습니다. 경계가 맞닿기만 하면 겹침이 아닙니다.
프로젝트·미디어가 바뀌면 다시 여세요. 검사는 편집하지 않으며 영상 탐색에는 정상
미디어 또는 확인한 세션 미디어 연결이 필요합니다. 자동 수정하지 않습니다.

**자막 검토**에서 읽기 속도·최소/최대 길이의 양수 기준을 선택해 입력하세요. 빈칸은
해당 검사를 끕니다. 길이는 배속 후 출력 초이며 최소는 최대보다 클 수 없습니다.
겹침은 기본으로 검사합니다. 전체 또는 한 종류를 고르면 최대 20개의 일치 문제와
전체 검사 개수·일치/생략 수를 보여 줍니다. 반복은 별도 발생 구간이며 겹침은 영향받은
발생 구간의 대표 문제이지 모든 쌍이 아닙니다.

기준을 바꾸면 다시 검사하세요. 필터 변경은 최신 검사에 대해 일치 보고서를 다시 계산하며
처음 20개만 거르는 것이 아닙니다. **자막**은 위치 이동 없이 작성 행에 초점을 옮기고
**구간 보기**는 일시 정지 후 해당 발생 위치로 이동합니다. 창을 연 채 프로젝트·미디어가
바뀌면 **검사**를 눌러 입력한 기준으로 새 보고서를 만들 수 있으며, 이전 결과의 이동은
계속 차단됩니다. 행으로 이동하면 창이 닫힙니다. 다시 열면 숫자 기준은 빈칸, 겹침은 켜짐,
필터는 전체로 시작합니다. 검사·이동은 편집·프로젝트 설정 저장·실행 취소 기록을 만들지 않습니다.
기준값은 편집기 설정에 남기지 않고 자동 수정하지 않으며 기존 **자막 시간 겹침** 항목도 유지합니다.

검사 후 **표시된 결과 저장 (.json)**은 현재 보고서를 `PROJECT.caption-findings.json`으로
내려받습니다. 선택한 기준·필터, 전체 개수, 일치·생략 수와 **화면에 표시된 최대 20개 결과**를
담습니다. JSON 키·**0부터 시작하는 인덱스**·**배속 후 출력 초**는 `captions.inspect`와
같으며 파일 내용에는 자막 원문·프로젝트 이름이 없습니다. 파일명에는 프로젝트 이름을 씁니다.
빈 필터 결과가 모든 검사 통과를 뜻하지 않으므로 필터·활성 검사·전체 개수를 함께 보세요.

결과 저장은 창을 닫거나 프로젝트·재생 위치·브라우저 저장소·기록을 바꾸지 않습니다.
원본 미디어 연결은 필요 없지만 작업 중·복구·오래된 보고서 보호는 유지합니다.
다운로드 오류가 나면 같은 보고서로 재시도할 수 있으며 브라우저의 다운로드 완료를
확인하는 기능은 아닙니다. 변경하지 않은 프로젝트 설정과 함께 보관하세요. 인덱스는
검사 시점의 위치일 뿐 다른 프로젝트에 적용하는 백업이나 규격 준수·실제 표시·음성 일치의 증명이 아닙니다.

<a id="split-range"></a>

## 긴 자막 범위 분할

일부만 나누려면 긴 자막 분할 옆 **범위…**에서 양 끝을 포함하는 1부터 시작하는
원본 행 번호를 입력하세요. 시작·끝은 현재 페이지 첫 자막 한 행으로 열리며,
선택한 12/18/24 프리셋을 가져와 창에서 바꿀 수 있습니다. 변경은 한 번에 실행
취소하며, 변화가 없으면 편집·일시 정지 없이 닫습니다. 범위 밖 문구·메타데이터·
시간 기준은 그대로입니다. 분할 경계 공백 제거와 시간 추정은 같으므로 음성과 비교하세요.

<a id="precise-times"></a>

## 정확한 자막 시간 편집

자막 행의 시작/끝 입력은 저장된 소수 초를 한 자리로 반올림하지 않고 표시하며,
한쪽을 편집해도 반대쪽 값은 유지합니다. 원본 또는 배속 전 타임라인 시간 기준과
기존 검증은 그대로입니다. 같은 값이어도 명시적인 change 이벤트는 기존 편집·기록
경로를 사용하며, 프레임/샘플 정확도나 같은 값의 기록 생략을 보장하는 변경은 아닙니다.

## 자막 페이지 이동

자막 편집 목록은 **페이지당 50행**을 표시하며 이전·다음 버튼과 표시 범위를
제공합니다. 50개를 넘으면 **1부터 시작하는 페이지 번호**를 입력하고 **이동**이나
Enter를 눌러 해당 페이지 첫 자막에 초점을 옮깁니다. 표시된 마지막 페이지까지
입력할 수 있으며 최대 200페이지입니다. 잘못된 입력은 초점을 유지하여 수정할 수 있고,
UI 언어를 바꿔도 입력 초안·초점을 유지합니다. 페이지만 바꾸면 편집·저장·실행 취소
기록·재생 위치는 변하지 않습니다. 검색·
타임라인 선택·가져오기·자막 추가 시 대상 행이 있는 페이지를 엽니다. 검색·
모두 바꾸기·전체 긴 자막 분할 버튼은 전체 원본 자막 목록을 대상으로 하며, 내보내기도
현재 페이지가 아닌 전체 프로젝트의 클립·배속 규칙을 따릅니다. 기존 10,000개·
2 MiB 한도는 그대로입니다.

<a id="remove-range"></a>

## 자막 범위 삭제

자막 도구의 **자막 범위 삭제…**는 페이지를 넘어 **1부터 시작하는 작성 행 번호**를
양끝 포함해 받습니다. 두 입력은 현재 페이지 첫 행에서 시작하며 검색 결과나 영상의
파생 구간 번호가 아닙니다. 전체 삭제도 가능합니다. 생존 자막은 타임라인 밖 구간을
포함해 그대로 유지하고 시간을 조정하지 않으며 한 번에 실행 취소합니다. 생존 행의
페이지나 빈 목록의 **자막 추가**로 초점을 옮기고, 재생은 현재 위치를 유지하며 정지합니다.
취소는 추가 편집 없이 페이지·검색 초안을 유지합니다. 창을 여는 과정의 일반적인
입력란 포커스 해제/변경 처리로 행 편집은 이미 반영될 수 있습니다. 구조 편집 뒤 위치를 다시 확인하세요.
유효한 복구 실패 상태의 편집은 브라우저 저장 대신 설정 파일 백업이 필요합니다.

<a id="import-subtitles"></a>

## 자막 파일 가져오기와 검토

**브라우저 SRT/VTT 가져오기:** 먼저 설정을 백업하세요. **전체 교체**(기본값) 또는
**기존 자막 유지 후 추가**를 고른 뒤 파일과 실제 타임스탬프 기준을 지정하세요.

| 가져올 시간 기준 | 사용할 파일 |
|---|---|
| **원본 미디어** (기본값) | 배속 전 원본 영상 기준 타임스탬프 |
| **편집된 출력** | 현재 편집 결과의 배속 후 타임스탬프; 가져오기 시 잡은 배속으로 저장용 타임라인 시간으로 변환 |

**파일 검토**로 읽고 파싱하되 자막은 바꾸지 않습니다. 개수를 확인한 뒤 교체 또는
추가를 확정하세요. 추가 모드는 가져온 뒤의 전체 개수를 10,000개 상한과 함께
표시합니다.

| 검토 개수 | 의미 |
|---|---|
| 가져올 자막 | 이 파서가 가져올 자막 |
| 그중 끝 시간이 잘린 자막 | 선택 길이에 맞춰 끝을 줄인 수용 자막의 부분집합; 수용 개수에 이미 포함 |
| 인식했지만 제외된 항목 | 패턴에 맞았지만 파싱한 본문이 비었거나 끝을 자른 뒤 양수 길이가 아니어서 제외한 후보 |

잘못된/인식하지 못한 구문은 **집계하지 않으므로** 전체 파일 개수나 완전한 SRT/VTT
검증이 아닙니다. 파일/기준/작업 방식 변경은 검토를 지우고, 프로젝트·미디어·창 변경은
검토를 무효화합니다. 확정은 검토한 비공개 파일 데이터를 사용하며 다시 읽지 않습니다.
두 모드 모두 한 번에
실행 취소하고 현재 재생 위치를 유지하며, 추가는 첫 새 행에 초점을 옮깁니다. 기준과
검토를 확인한 뒤 확정하세요. 자동 판별이나 기존 자막 기준 이동은 하지 않습니다.

**기존 자막 유지 후 추가**는 현재 편집 길이 밖의 유효한 자막도 포함해 기존 행·화자·키워드·
순서를 유지합니다. 새 자막은 영상 끝이 아닌 목록 끝에 붙이며 파일의 절대 시간을
유지합니다. 정렬·시간 이동·병합·중복 제거는 하지 않고 파일에서 화자 정보도 복원하지
않습니다. 추가 모드로 다시 가져오면 중복되며 겹치는 자막은 가려질 수 있습니다.
전체 교체는 현재 페이지뿐 아니라 기존 자막 전부를 지웁니다.

출력 자막에는 반복 클립이 이미 펼쳐져 있으므로 출력 기준으로 가져오면 원본 구간으로
역매핑하지 않고 타임라인 자막으로 유지합니다. 이후 컷·배속 변경은 기존 타임라인 자막
규칙을 따릅니다. **출력 기준 자막을 가져오기 전에 추가 오디오 오프셋을 정하세요.**
기존 브라우저 오프셋 조절은 오디오에서 생성한 자막만이 아니라 가져온 자막을 포함한
**모든 타임라인 기준 자막**을 함께 이동합니다. 실수했다면 오프셋 편집 전체를 실행
취소하세요. 이후 컷 편집이 가져온 파일을 자동 재정렬하지는 않습니다. 밀리초 반올림·제거된 마크업·화자/스타일/키워드 정보는 복원하지 않아
무손실 왕복이 아닙니다. 취소·거절·오래된 요청은 자막을 교체하지 않습니다.
기본 옵션의 프로그램 가져오기와 기존 숨긴 파일 선택기는 원본 기준 전체 교체를 유지합니다.
유효한 복구 실패 상태에서는 메모리 편집만 가능하며 브라우저 저장은 계속 막힙니다.
CLI/MCP `captions.import`는 여전히 원본 또는 **배속 전** 타임라인만 받으며 이 브라우저
출력 기준 옵션을 추가한 것이 아닙니다.

세미콜론으로 끝나는 10진수 `&#54620;`와 16진수 `&#x4E2D;`/`&#X4E2D;`는
태그 제거 뒤 한 번만 해석합니다(예: `한中`). 숫자 범위는 U+0020–U+10FFFF이며
DEL/C1(U+007F–009F), U+2028/U+2029, 서로게이트, U+FDD0–FDEF 및 각 평면의
U+FFFE/U+FFFF는 제외합니다. 잘못됐거나 지원하지 않는 표기(TAB/LF/FF/CR 참조 포함)는
원문 그대로 두며 HTML 오류 복구나 제어 문자 치환을 하지 않습니다. 유효한 서식·공백
문자도 보이지 않을 수 있으므로 표시 여부는 보장하지 않습니다. `&amp;#54620;`는
문자 그대로의 `&#54620;`로 남고 인코딩된 태그도 텍스트로 유지합니다. 해석된 공백은
자르지 않으므로 공백뿐인 자막은 내보내기에서 거절될 수 있습니다. 구간당 2,000 UTF-16
코드 단위 한도는 해석 후 적용하고 원본 입력의 바이트·명령 길이 한도는 유지합니다.

## 범위 시간 이동

일부 자막만 지연됐다면 자막 도구의 **자막 범위 시간 이동…**에서 양끝을 포함한
**1부터 시작하는 작성 행 번호**, 원본/배속 전 타임라인 기준, 부호 있는 초를 입력하세요.
처음/마지막은 현재 페이지 첫 행, 기준은 원본, 이동은 0초로 시작하며 선택을 추측하지
않습니다. 페이지를 넘어 범위 안에서 해당 기준만 이동하고 시간 기준을 변환하지 않습니다.
실제 변경은 한 번에 실행 취소하며 재생 위치는 유지합니다. 취소·0초·실제 변경 없음은
추가 편집을 만들지 않지만 열기 전 일반 포커스 해제 처리로 초안이 이미 반영될 수 있습니다.
기존 전체 자막 이동도 그대로 사용할 수 있습니다.

## 범위 화자 지정

**여러 자막에 같은 화자를 지정하려면:** 자막 도구의 **범위 화자 지정…**을 여세요.

- 양끝을 포함한 **1부터 시작하는 작성 행 번호**를 입력합니다. 기본값은 현재 페이지 첫 행과 그 행의 화자이며 검색/출력 출현 선택이 아닙니다.
- 기존 화자 둘 중 하나 또는 미배정을 선택합니다. 시간 기준이 섞여도 문구·시간·순서를 그대로 두고 배정만 바꿉니다.
- 실제 변경은 한 단계 실행 취소, 취소·동일 배정은 추가 편집이 없습니다. 이름·색은 기존 대사 공통 설정이며 자동 화자 인식은 아닙니다. [CLI/MCP 계약](../INTEGRATIONS.md#자막-범위의-화자-배정)
